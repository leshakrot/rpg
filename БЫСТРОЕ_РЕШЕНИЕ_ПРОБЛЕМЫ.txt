═══════════════════════════════════════════════════════════════════════════════

Я ИСПРАВИЛ СИСТЕМУ! Теперь выполните следующие шаги:

═══════════════════════════════════════════════════════════════════════════════

ШАГ 1: ПЕРЕЗАПУСТИТЕ UNITY EDITOR
----------------------------------
→ Закройте Unity
→ Откройте проект заново
→ Дождитесь компиляции скриптов

═══════════════════════════════════════════════════════════════════════════════

ШАГ 2: ПРОВЕРЬТЕ СИСТЕМУ
-------------------------
→ Меню: Tools > Validate > Check Highlight System
→ Посмотрите результаты в Console
→ Если есть предупреждения о материалах, переходите к Шагу 3

═══════════════════════════════════════════════════════════════════════════════

ШАГ 3: ИСПРАВЬТЕ МАТЕРИАЛЫ (если нужно)
----------------------------------------
Вариант А - Автоматическое исправление:
  1. Выберите проблемный объект в Hierarchy
  2. Меню: Tools > Debug > Fix Material Emission Settings
  3. Повторите для всех проблемных объектов

Вариант Б - Ручное исправление:
  1. Выберите материал в Project
  2. Измените Shader на:
     • Standard (для Built-in RP)
     • Universal Render Pipeline/Lit (для URP)
     • HDRP/Lit (для HDRP)

═══════════════════════════════════════════════════════════════════════════════

ШАГ 4: ПРИМЕНИТЕ ЦВЕТОВЫЕ ПРЕСЕТЫ
----------------------------------
→ Меню: Tools > Highlight Colors > Apply All Presets

Это применит правильные цвета:
  • Ресурсы (деревья, руда) → Зеленый
  • NPC → Голубой
  • Магазины → Золотой
  • Сундуки → Оранжевый
  • Враги → Красный

═══════════════════════════════════════════════════════════════════════════════

ШАГ 5: ПРОТЕСТИРУЙТЕ
---------------------
1. Запустите Play Mode
2. Наведите курсор на интерактивные объекты
3. Они должны подсвечиваться ЦВЕТОМ, а не белым!

═══════════════════════════════════════════════════════════════════════════════

ЕСЛИ ВСЕ ЕЩЕ БЕЛЫЙ ЦВЕТ:
-------------------------

1. Выберите проблемный объект в Play Mode
2. В Inspector найдите InteractableHighlight
3. Проверьте:
   ✓ Highlight Color - должен быть ЦВЕТНОЙ (не белый)
   ✓ Highlight Intensity - должен быть 1.0-2.0
   ✓ Компонент должен быть ВКЛЮЧЕН (галочка)

4. Если цвет белый - измените его вручную:
   • Кликните на Highlight Color
   • Выберите яркий цвет (например, желтый или оранжевый)
   • Установите Highlight Intensity = 1.5

═══════════════════════════════════════════════════════════════════════════════

ДИАГНОСТИКА КОНКРЕТНОГО ОБЪЕКТА:
---------------------------------

1. Выберите объект в Hierarchy
2. Меню: Tools > Debug > Analyze Selected Object Materials
3. Проверьте Console - там будет детальный отчет:
   ✓ Есть ли Renderer?
   ✓ Поддерживают ли материалы _EmissionColor?
   ✓ Какой Shader используется?

═══════════════════════════════════════════════════════════════════════════════

ЧТО Я ИСПРАВИЛ:
---------------

✓ Теперь система создает ИНСТАНСЫ материалов (не меняет shared materials)
✓ Правильно сохраняет и восстанавливает оригинальные значения Emission
✓ Поддерживает как _EmissionColor, так и _EmissiveColor (URP/HDRP)
✓ Улучшена диагностика и отладка
✓ Добавлены инструменты для исправления материалов

═══════════════════════════════════════════════════════════════════════════════

НОВЫЕ ИНСТРУМЕНТЫ ОТЛАДКИ:
---------------------------

Tools > Debug >
  • Analyze Selected Object Materials - детальный анализ материалов
  • Test Highlight on Selected - тест подсветки на 2 секунды
  • Fix Material Emission Settings - автоматическое исправление

═══════════════════════════════════════════════════════════════════════════════

ВАЖНО:
------
После перезапуска Unity и выполнения шагов выше, подсветка должна работать
с ПРАВИЛЬНЫМИ ЦВЕТАМИ на ВСЕХ объектах с поддерживаемыми материалами!
