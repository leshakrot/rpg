# GameHUD для RPG проекта

## Описание
GameHUD - это префаб пользовательского интерфейса для RPG игры, который отображает следующие параметры:
1. Здоровье игрока
2. Мана игрока
3. Уровень игрока
4. Опыт игрока
5. Здоровье выбранной цели (врага)

## Установка

### Импорт скриптов
Убедитесь, что следующие скрипты добавлены в ваш проект:
- `UI/StatusBar.cs` - базовый класс для всех полос состояния
- `UI/PlayerHealthBar.cs` - отображение здоровья игрока
- `UI/PlayerManaBar.cs` - отображение маны игрока
- `UI/PlayerExperienceBar.cs` - отображение опыта игрока
- `UI/PlayerLevelDisplay.cs` - отображение уровня игрока
- `UI/EnemyTargetHealthBar.cs` - отображение здоровья текущей цели
- `UI/GameHUD.cs` - основной скрипт, управляющий всеми элементами HUD
- `UI/HUDTester.cs` (опционально) - скрипт для тестирования HUD

### Создание префаба
1. Следуйте инструкциям в файле `GameHUD.prefab.txt` для создания всех необходимых игровых объектов
2. Настройте ссылки всех компонентов в инспекторе Unity
3. Сохраните готовую структуру как префаб

## Использование

### Добавление HUD на сцену
1. Перетащите префаб GameHUD на вашу сцену
2. Префаб автоматически найдет игрока с тегом "Player" и будет отображать его параметры

### Тестирование
1. Добавьте компонент `HUDTester` на любой GameObject на сцене
2. Настройте клавиши тестирования в инспекторе
3. Запустите игру и используйте следующие клавиши (по умолчанию):
   - Q - уменьшить здоровье игрока
   - W - увеличить здоровье игрока
   - A - уменьшить ману игрока
   - S - увеличить ману игрока
   - E - добавить опыт игроку

## Настройка внешнего вида
Вы можете легко настроить внешний вид HUD:
1. Измените цвета полос в инспекторе или в коде (свойство `barColor`)
2. Настройте размеры панелей и полос через RectTransform
3. Измените шрифты и размеры текста через компоненты TextMeshPro
4. Включите/отключите автоматическое скрытие полосы при полном/пустом значении через свойства `hideWhenFull` и `hideWhenEmpty`

## Зависимости
- Требуется TextMeshPro для текстовых элементов
- Необходимы следующие компоненты у игрока: Health, Mana, BaseStats, Experience
- Для отображения здоровья врага необходим компонент PlayerFighter у игрока

## Возможные проблемы и их решение
1. **Не отображается HUD**: Убедитесь, что игрок имеет тег "Player" и все необходимые компоненты
2. **Полосы не меняются**: Проверьте настройки ссылок в инспекторе для каждого компонента StatusBar
3. **Некорректное отображение текста**: Убедитесь, что компоненты TextMeshPro настроены правильно
