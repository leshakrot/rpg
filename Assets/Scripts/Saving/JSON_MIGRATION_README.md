# Миграция системы сохранений на JSON

## Обзор изменений

Система сохранений была переведена с BinaryFormatter на JSON для улучшения производительности, читаемости и совместимости с новыми версиями Unity.

## Основные изменения

### 1. SavingSystem.cs
- Заменен BinaryFormatter на Newtonsoft.Json
- Изменено расширение файлов с `.sav` на `.json`
- Добавлена обработка ошибок с логированием
- Добавлены кастомные конвертеры для типов Unity

### 2. Новые файлы
- `SerializableQuaternion.cs` - сериализуемая обертка для Quaternion
- `JsonConverters.cs` - кастомные JSON конвертеры для Vector3, Quaternion, Color

### 3. Обновленные файлы
- Все ISaveable скрипты обновлены с добавлением `using Newtonsoft.Json`
- Добавлены JsonProperty атрибуты для структур данных
- Исправлены проблемы с сериализацией вращений в Mover.cs

## Совместимость

### Обратная совместимость
- Старые `.sav` файлы не будут загружены автоматически
- Для миграции старых сохранений требуется отдельный скрипт конвертации

### Unity версии
- Совместимо с Unity 2021.3 и новее
- Полностью совместимо с Unity 6000.x
- Решает проблемы безопасности BinaryFormatter

## Преимущества JSON

1. **Читаемость**: Файлы сохранений можно открыть и прочитать в любом текстовом редакторе
2. **Отладка**: Легче найти и исправить проблемы с данными сохранений
3. **Совместимость**: Работает на всех платформах без ограничений
4. **Безопасность**: Избегает проблем безопасности BinaryFormatter
5. **Производительность**: Более быстрая сериализация/десериализация

## Структура файлов сохранений

Новые файлы сохранений имеют следующую структуру:
```json
{
  "UniqueID1": {
    "$type": "FullTypeName",
    "property1": "value1",
    "property2": 123
  },
  "UniqueID2": {
    "position": {"x": 1.0, "y": 2.0, "z": 3.0},
    "rotation": {"x": 0.0, "y": 0.0, "z": 0.0, "w": 1.0}
  }
}
```

## Миграция старых сохранений

Для миграции старых `.sav` файлов в новый формат `.json`:

1. Создайте резервную копию папки с сохранениями
2. Используйте утилиту миграции (если необходимо)
3. Тестируйте новые сохранения перед удалением старых

## Устранение неполадок

### Ошибки приведения типов (InvalidCastException)
**Проблема**: `InvalidCastException: Specified cast is not valid` при загрузке сохранений

**Причина**: JSON десериализует числа как `double`, а не `float`

**Решение**: Используйте `JsonSaveHelper.ToFloat()`, `JsonSaveHelper.ToInt()`, `JsonSaveHelper.ToBool()` вместо прямого приведения типов

```csharp
// Неправильно
public void RestoreState(object state)
{
    healthPoints = (float)state; // Может вызвать InvalidCastException
}

// Правильно
public void RestoreState(object state)
{
    healthPoints = JsonSaveHelper.ToFloat(state); // Безопасное приведение
}
```

### Ошибки сериализации
- Проверьте, что все классы данных помечены как `[Serializable]`
- Убедитесь, что поля данных помечены `[JsonProperty]`
- Проверьте логи Unity на предмет ошибок JSON

### Проблемы с типами Unity
- Используйте SerializableVector3 и SerializableQuaternion для Vector3 и Quaternion
- Кастомные конвертеры автоматически обрабатывают основные типы Unity

### Производительность
- JSON файлы могут быть больше по размеру чем бинарные
- Время загрузки обычно быстрее благодаря оптимизации Newtonsoft.Json
