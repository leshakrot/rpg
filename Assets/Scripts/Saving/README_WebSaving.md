# Интегрированная система сохранений с YandexSDK

## Обзор

Данная система решает проблему работы сохранений в веб-билдах Unity, интегрируя существующую систему сохранений с YandexSDK. Система автоматически определяет платформу и использует подходящий метод хранения данных:

- **В редакторе и десктопных билдах**: файловая система
- **В веб-билдах**: YandexSDK (облачные сохранения + локальное хранилище браузера)

## Основные компоненты

### 1. WebSavingAdapter
Главный адаптер для работы с YandexSDK. Обеспечивает:
- Сохранение/загрузка игровых данных через YandexSDK
- Поддержка множественных слотов сохранения (slot1, slot2, slot3)
- Автоматическая синхронизация с облачными сохранениями Яндекса

### 2. SavingSystem (обновленный)
Основная система сохранений, теперь с поддержкой веб-платформы:
- Автоматическое определение платформы
- Ожидание готовности YandexSDK в веб-билдах
- Прозрачная работа с различными типами хранилища

### 3. SavingWrapper (обновленный)
Обертка для управления сохранениями:
- Поддержка веб-платформы
- Автоматическое использование слотов по умолчанию в веб-версии
- События для отслеживания операций сохранения

### 4. WebSavingInitializer
Компонент инициализации для веб-платформы:
- Ожидание готовности YandexSDK
- Управление процессом инициализации
- Отладочная информация

### 5. WebSavingDemo
Демонстрационный компонент с UI для тестирования системы.

## Настройка

### 1. Обновление SavesYG.cs

В файле `/Assets/YandexGame/WorkingData/SavesYG.cs` уже добавлены поля для игровых сохранений:

```csharp
// Слоты для сохранения игровых данных
public string gameSaveSlot1 = "";
public string gameSaveSlot2 = "";
public string gameSaveSlot3 = "";
```

### 2. Настройка сцены

1. **Добавьте WebSavingInitializer** на основной GameObject (например, на тот же, где находится YandexGame):
   ```
   GameObject -> Add Component -> Web Saving Initializer
   ```

2. **Настройте SavingSystem**:
   - Убедитесь, что флаг "Wait For Yandex SDK" установлен в true
   - Установите максимальное время ожидания (Max Wait Time)

3. **Настройте SavingWrapper**:
   - Убедитесь, что флаг "Use Web Adapter" установлен в true

### 3. Настройка YandexGame

В настройках InfoYG.asset убедитесь, что:
- Включены облачные сохранения (Save Cloud)
- Настроена синхронизация с локальным хранилищем (Local Save Sync)

## Использование

### Базовое использование

Система работает прозрачно - используйте существующие методы:

```csharp
// Сохранение
savingWrapper.Save();

// Загрузка
savingWrapper.Load();

// Загрузка определенного слота
savingWrapper.LoadGame("slot1");

// Новая игра
savingWrapper.NewGame("slot1");
```

### Работа со слотами в веб-версии

В веб-версии доступны три предустановленных слота:
- `"slot1"` - слот по умолчанию
- `"slot2"` - второй слот
- `"slot3"` - третий слот

```csharp
// Проверка существования слота
bool saveExists = savingSystem.SaveFileExists("slot1");

// Удаление слота
savingSystem.Delete("slot2");

// Получение списка доступных слотов
foreach(string slot in savingSystem.ListSaves())
{
    Debug.Log($"Доступен слот: {slot}");
}
```

### События веб-адаптера

```csharp
// Подписка на события
WebSavingAdapter.OnSaveLoaded += OnSaveLoadedHandler;
WebSavingAdapter.OnSaveSaved += OnSaveSavedHandler;

private void OnSaveLoadedHandler()
{
    Debug.Log("Сохранения загружены через YandexSDK");
}

private void OnSaveSavedHandler()
{
    Debug.Log("Сохранения записаны в YandexSDK");
}
```

### Принудительная синхронизация

```csharp
// Принудительная загрузка из YandexSDK
webInitializer.ForceLoadData();

// Принудительное сохранение в YandexSDK
webInitializer.ForceSaveData();
```

## Отладка

### Логи

Система выводит подробные логи:
- Статус инициализации YandexSDK
- Операции сохранения/загрузки
- Ошибки и предупреждения

### Компиляционные директивы

Используйте `#if UNITY_WEBGL && !UNITY_EDITOR` для кода, специфичного для веб-билдов.

### Общие проблемы

1. **Сохранения не работают в веб-билде**:
   - Проверьте инициализацию YandexSDK
   - Убедитесь, что WebSavingInitializer добавлен на сцену
   - Проверьте настройки InfoYG

2. **Долгое ожидание загрузки**:
   - Увеличьте Max Wait Time в WebSavingInitializer
   - Проверьте подключение к интернету

3. **Ошибки компиляции**:
   - Убедитесь, что YandexSDK правильно интегрирован
   - Проверьте наличие всех необходимых using директив
