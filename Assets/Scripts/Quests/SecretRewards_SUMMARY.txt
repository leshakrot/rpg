1. ОСНОВНЫЕ ИЗМЕНЕНИЯ:
   - Quest.Reward теперь имеет поле bool isSecret = false

   - Обновлен RewardPropertyDrawer для отображения чекбокса в Inspector
   - QuestEditor теперь поддерживает редактирование тайных наград

2. НОВЫЕ КОМПОНЕНТЫ:
   - QuestRewardHelper.cs - утилитарные методы для работы с наградами

   - SecretRewardDemo.cs - демонстрационный скрипт с примерами

3. ОБНОВЛЕННЫЕ КОМПОНЕНТЫ:
   - QuestTooltipUI.cs - теперь показывает только видимые награды + "???"
   - QuestGiver.cs - добавлены методы для работы с тайными наградами

4. РЕДАКТОРЫ И УТИЛИТЫ:
   - QuestSecretRewardMigrator.cs - инструмент для массового обновления квестов
   - README_SecretRewards.md - полная документация системы

🎯 КАК ИСПОЛЬЗОВАТЬ:

1. В INSPECTOR КВЕСТА:
   - Откройте любой Quest ScriptableObject
   - В секции Rewards увидите новое поле "Тайная награда"
   - Отметьте галочкой для скрытых наград

2. В QUEST EDITOR:
   - Window → RPG Tools → Quest Editor
   - Выберите квест
   - В Rewards секции отметьте "Тайная награда"

3. В КОДЕ:
   ```csharp
   // Получить только видимые награды (для UI превью)
   var visibleRewards = quest.GetVisibleRewards();
   
   // Получить все награды (при завершении квеста)
   var allRewards = quest.GetRewards();
   
   // Проверить наличие тайных наград
   bool hasSecrets = QuestRewardHelper.HasSecretRewards(quest);
   ```
