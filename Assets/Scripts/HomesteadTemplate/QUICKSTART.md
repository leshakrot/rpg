# Быстрый старт - Homestead Template

## 🚀 Создание шаблона за 3 шага

### Шаг 1: Откройте генератор
```
Unity Editor → Tools → Homestead → Create Template Scene
```

### Шаг 2: Создайте шаблон
Нажмите большую кнопку **"Создать шаблон-пример"** и подтвердите.

### Шаг 3: Тестируйте!
Сцена откроется автоматически. Нажмите Play и подойдите к желтым маркерам.

---

## 🎮 Что можно делать

### Строить здания
1. Подойдите к желтому маркеру (слоту)
2. Нажмите ЛКМ
3. Выберите здание
4. Нажмите "Build"

### Улучшать здания
1. Откройте меню построенного здания
2. Нажмите "Upgrade"
3. Здание станет больше и лучше

### Сносить здания
1. Откройте меню построенного здания
2. Нажмите "Demolish"
3. Подтвердите снос
4. Здание можно построить снова **БЕСПЛАТНО**!
