## 🛠️ Инструменты

После создания шаблона доступны:

```
Tools → Homestead → Template → ...
```

- **Open Documentation** → открыть README.md
- **Open Quick Start** → открыть QUICKSTART.md
- **Open Template Scene** → открыть сцену
- **Open Template Folder** → папка в проводнике
- **Show Template Info** → информация
