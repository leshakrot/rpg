# Homestead Template Generator

## Описание

Автоматический генератор шаблона-примера системы Homestead. Создает полнофункциональную демонстрационную сцену, которая показывает **ВСЕ** возможности системы Homestead.

## Как использовать

### Создание шаблона

1. В Unity Editor откройте меню: **Tools → Homestead → Create Template Scene**
2. В открывшемся окне нажмите кнопку **"Создать шаблон-пример"**
3. Подтвердите создание
4. Дождитесь завершения процесса (прогресс-бар покажет этапы)
5. Автоматически откроется созданная сцена **HomesteadTemplate.unity**

### Что создается

Генератор автоматически создает:

#### 📁 Структура папок
```
Assets/HomesteadTemplate/
├── Buildings/          # 5 примеров BuildingData
├── Requirements/       # Все типы требований
├── Prefabs/           # Префабы зданий (3 уровня каждого)
├── Materials/         # Материалы для визуализации
├── Scenes/            # Демонстрационная сцена
└── README.md          # Документация
```

#### 🏠 Здания (5 типов)

1. **Базовый дом (House_Basic)**
   - 3 уровня улучшений
   - Требования: дерево, камень, золото
   - Категория: "Жилые здания"
   - **Демонстрирует**: базовую систему строительства и улучшений

2. **Мастерская (Workshop)**
   - 2 уровня
   - Требования: пререквизит (дом), ресурсы
   - Категория: "Производственные здания"
   - **Демонстрирует**: систему пререквизитов (требует построенный дом)

3. **Склад (Storage)**
   - 1 уровень
   - **Лимит: максимум 3 штуки**
   - Категория: "Вспомогательные здания"
   - **Демонстрирует**: лимиты на количество зданий

4. **Ферма (Farm)**
   - 2 уровня
   - Требования: **логический OR** (дерево ИЛИ камень на выбор)
   - Категория: "Производственные здания"
   - **Демонстрирует**: логические операторы (OR)

5. **Сторожевая башня (Tower)**
   - 3 уровня
   - Требования: **уровень игрока** (5, 10, 15)
   - Категория: "Оборонительные сооружения"
   - **Демонстрирует**: интеграцию с системой уровней

#### 🎯 Слоты для строительства (8 штук)

Сцена содержит 8 слотов с разными конфигурациями:

- **Slot_House_1, Slot_House_2** - только дома
- **Slot_Universal_1, Slot_Universal_2** - все типы зданий
- **Slot_Production_1, Slot_Production_2** - мастерская и ферма
- **Slot_Defense_1, Slot_Defense_2** - только башни

Каждый слот визуализирован желтой сферой и имеет радиус взаимодействия 3 метра.

#### ✅ Типы требований

Шаблон демонстрирует **ВСЕ** типы требований системы:

1. **InventoryRequirement** - требования к предметам в инвентаре
   - Пример: "Дерево x10", "Камень x20"

2. **CurrencyRequirement** - требования к валюте
   - Пример: "100 Gold", "500 Gold"

3. **QuestRequirement** - требования к квестам
   - (Можно добавить, если есть тестовые квесты)

4. **LevelRequirement** - требования к уровню игрока
   - Пример: "Player Level 5", "Player Level 10"

5. **PrerequisiteBuildingRequirement** - требования к другим зданиям
   - Пример: "Requires: Базовый дом (Level 1+)"

6. **LogicalRequirement** - логические операторы
   - Пример: "(OR): Дерево x20 OR Камень x15"

## Как тестировать

### Запуск сцены

1. Откройте сцену **HomesteadTemplate.unity**
2. Нажмите Play
3. Подойдите к любому желтому маркеру (слоту)
4. Нажмите ЛКМ для открытия меню строительства

### Тестовые сценарии

#### Сценарий 1: Базовое строительство
1. Подойдите к Slot_House_1
2. Выберите "Базовый дом"
3. Проверьте требования (дерево x10, 100 золота)
4. Постройте здание
5. Здание появится на слоте

#### Сценарий 2: Улучшение
1. Постройте Базовый дом (уровень 1)
2. Откройте меню снова
3. Нажмите кнопку "Upgrade"
4. Здание улучшится до уровня 2 (больше размер)

#### Сценарий 3: Бесплатная реконструкция
1. Постройте любое здание
2. Снесите его (кнопка "Demolish")
3. Постройте то же здание снова
4. Требования будут помечены как [FREE]
5. Ресурсы не спишутся

#### Сценарий 4: Пререквизиты
1. Попробуйте построить Мастерскую
2. Требование "Requires: Базовый дом" будет красным (✗)
3. Постройте Базовый дом
4. Требование станет зеленым (✓)
5. Теперь можно построить Мастерскую

#### Сценарий 5: Лимиты
1. Постройте 3 Склада на разных слотах
2. Попробуйте построить 4-й
3. Строительство будет заблокировано (лимит достигнут)

#### Сценарий 6: Логические операторы
1. Откройте меню для Фермы
2. Увидите требование "(OR): Дерево x20 OR Камень x15"
3. Достаточно иметь ЛИБО дерево, ЛИБО камень
4. Не нужно иметь оба ресурса

#### Сценарий 7: Требования уровня
1. Попробуйте построить Башню
2. Требование "Player Level 5" будет красным
3. Повысьте уровень игрока до 5+
4. Требование станет зеленым
5. Можно построить Башню

## Визуализация

### Цвета зданий
- 🟡 **Желтый** - Дом (жилое здание)
- 🔵 **Синий** - Мастерская (производство)
- ⚪ **Серый** - Склад (хранение)
- 🟢 **Зеленый** - Ферма (сельское хозяйство)
- 🔴 **Красный** - Башня (оборона)

### Размеры по уровням
- **Уровень 1** - маленький
- **Уровень 2** - средний
- **Уровень 3** - большой

## Адаптация под свой проект

### Замена визуализации
1. Откройте папку `HomesteadTemplate/Prefabs/`
2. Замените простые кубы на свои 3D модели
3. Сохраните префабы с теми же именами

### Изменение требований
1. Откройте `HomesteadTemplate/Buildings/[название].asset`
2. В Inspector измените массив `Level Requirements`
3. Добавьте/удалите требования по необходимости

### Добавление новых зданий
1. Создайте новый BuildingData: `Create → Homestead → Building Data`
2. Настройте параметры
3. Создайте префабы для каждого уровня
4. Создайте требования
5. Добавьте здание в `allowedBuildings` нужных слотов

### Создание новых слотов
1. Создайте пустой GameObject
2. Добавьте компонент `BuildingSlot`
3. Настройте:
   - Slot ID (уникальный)
   - Allowed Buildings (массив)
   - Slot Category
   - Interaction Radius

## Требования к проекту

Для работы шаблона необходимо:

1. ✅ Установленная система Homestead
2. ✅ Тестовые предметы:
   - `Assets/Game/Inventories/Resources/Wood.asset`
   - `Assets/Game/Inventories/Resources/Stone.asset`
3. ✅ Система инвентаря (GameDevTV.Inventories)
4. ✅ Система валюты (RPG.Inventories.Purse)
5. ✅ Система уровней (RPG.Stats.BaseStats)

**Примечание**: Если тестовые предметы не найдены, генератор пропустит их, но здания все равно будут созданы.

## Удаление шаблона

Если нужно удалить шаблон:

1. Откройте **Tools → Homestead → Create Template Scene**
2. Нажмите кнопку **"Удалить шаблон"**
3. Подтвердите удаление

Будет удалена вся папка `Assets/HomesteadTemplate/` со всем содержимым.

## Техническая информация

### Создаваемые файлы

**BuildingData** (5 файлов):
- House_Basic.asset
- Workshop.asset
- Storage.asset
- Farm.asset
- Tower.asset

**Requirements** (~30 файлов):
- Inventory requirements (Wood, Stone)
- Currency requirements (Gold)
- Level requirements (5, 10, 15)
- Prerequisite requirements
- Logical requirements (OR)

**Prefabs** (15 файлов):
- По 3 префаба для каждого здания (уровни 1-3)
- Или 1-2 префаба для зданий с меньшим количеством уровней

**Materials** (15 файлов):
- Материалы для каждого префаба

**Scenes** (1 файл):
- HomesteadTemplate.unity

### Используемые технологии

- **Reflection** - для установки приватных полей ScriptableObject
- **PrefabUtility** - для создания префабов
- **EditorSceneManager** - для создания сцены
- **AssetDatabase** - для управления ассетами
