# Установка и использование Homestead Template Generator

## 📦 Что это?

**Homestead Template Generator** - это инструмент для автоматического создания полнофункционального шаблона-примера системы Homestead. Он создает демонстрационную сцену со всеми возможностями системы.

## ✅ Требования

Перед использованием убедитесь, что у вас установлено:

1. ✅ **Система Homestead** (Assets/Scripts/Homestead/)
2. ✅ **GameDevTV Inventories** (система инвентаря)
3. ✅ **RPG Core Systems** (Purse, Stats, Quests)
4. ✅ **Saving System** (GameDevTV.Saving)

## 🚀 Быстрый старт

### 1. Откройте генератор

В Unity Editor:
```
Tools → Homestead → Create Template Scene
```

### 2. Создайте шаблон

В открывшемся окне нажмите:
```
"Создать шаблон-пример"
```

Подтвердите создание и дождитесь завершения (5-10 секунд).

### 3. Готово!

Сцена **HomesteadTemplate.unity** откроется автоматически.

## 🎮 Как использовать

### В режиме Play

1. Откройте сцену `HomesteadTemplate.unity`
2. Нажмите **Play**
3. Подойдите к желтому маркеру (слоту)
4. Нажмите **ЛКМ** для открытия меню
5. Выберите здание и постройте его

### Типы зданий

| Здание | Цвет | Уровни | Демонстрирует |
|--------|------|--------|---------------|
| Дом | 🟡 Желтый | 3 | Базовое строительство |
| Мастерская | 🔵 Синий | 2 | Пререквизиты |
| Склад | ⚪ Серый | 1 | Лимиты (max 3) |
| Ферма | 🟢 Зеленый | 2 | Логические OR |
| Башня | 🔴 Красный | 3 | Требования уровня |

## 🛠️ Дополнительные инструменты

После создания шаблона доступны:

```
Tools → Homestead → Template → ...
```

- **Open Documentation** - открыть полную документацию
- **Open Quick Start** - открыть краткую инструкцию
- **Open Template Scene** - открыть демо-сцену
- **Open Template Folder** - открыть папку в проводнике
- **Show Template Info** - показать информацию о шаблоне

## 🔧 Настройка

### Изменение визуализации

Замените простые кубы на свои 3D модели:

1. Откройте `HomesteadTemplate/Prefabs/`
2. Замените префабы на свои модели
3. Сохраните с теми же именами

### Изменение требований

1. Откройте `HomesteadTemplate/Buildings/[здание].asset`
2. В Inspector измените `Level Requirements`
3. Добавьте/удалите требования

### Добавление зданий

1. Создайте `BuildingData`: `Create → Homestead → Building Data`
2. Настройте параметры
3. Создайте префабы
4. Добавьте в `allowedBuildings` слотов

## 🗑️ Удаление шаблона

Если нужно удалить:

1. `Tools → Homestead → Create Template Scene`
2. Нажмите **"Удалить шаблон"**
3. Подтвердите

Будет удалена вся папка `Assets/HomesteadTemplate/`.

## ❓ Проблемы и решения

### Ошибка: "Wood.asset not found"

**Решение**: Создайте тестовые предметы:
- `Assets/Game/Inventories/Resources/Wood.asset`
- `Assets/Game/Inventories/Resources/Stone.asset`

Или измените пути в генераторе.

### Ошибка: "ConstructionMenu prefab not found"

**Решение**: Сначала запустите:
```
Homestead → Setup Homestead Scene
```

Это создаст UI префаб.

### Здания не появляются

**Проверьте**:
1. EstateManager есть на сцене
2. BuildingsParent назначен
3. Слоты зарегистрированы
4. Префабы не null
