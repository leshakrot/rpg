# Улучшенная атмосферная система дня и ночи

## Обзор улучшений

Система была значительно улучшена для создания более атмосферной и ламповой стилистики, оптимизированной для браузерных и мобильных игр.

## Ключевые улучшения

### 🌅 Новый атмосферный шейдер
- **AtmosphericSkyboxMobile.shader** - оптимизированный для мобильных устройств
- Звезды появляются **только ночью** автоматически
- Улучшенный атмосферный градиент с теплыми тонами
- Эффект мерцания звезд
- Настройки теплоты/прохлады атмосферы

### 🎨 URP Volume интеграция
- **URPVolumeController** - автоматическая настройка Global Volume
- Динамические цветовые коррекции (яркость, контраст, насыщенность)
- Температурные эффекты (теплые дни, прохладные ночи)
- Оптимизация для разных платформ

### 🛠️ Улучшенный Setup Helper
- Автоматическое создание атмосферных градиентов
- Быстрые настройки для ламповой атмосферы
- Оптимизация для мобильных/ПК
- Интеграция с URP Volume

## Как использовать

### Шаг 1: Создание нового skybox материала
1. В Project Window: `ПКМ → Create → Material`
2. Назовите материал `AtmosphericSkyboxMobile`
3. В Inspector установите Shader: `Custom/AtmosphericSkyboxMobile`
4. Настройте параметры:
   - **Sky Color**: (0.5, 0.7, 1.0) - теплые дневные тона
   - **Horizon Color**: (1.0, 0.8, 0.6) - теплые закатные оттенки
   - **Ground Color**: (0.2, 0.15, 0.1) - темно-коричневые тона
   - **Warmth Factor**: 0.15 - для теплой атмосферы
   - **Star Density**: 60-80 - оптимально для мобильных
   - **Star Brightness**: 0.8
   - **Star Twinkle**: 0.3

### Шаг 2: Настройка в DayNightSystem
1. Перетащите созданный материал в поле `Skybox Material`
2. Откройте `Tools → Day Night System → Setup Helper`
3. Выберите ваш DayNightSystem в поле `Day Night System`
4. Нажмите `Создать улучшенный атмосферный skybox` для инструкций
5. Нажмите `Настроить для ламповой атмосферы` для автоматической настройки

### Шаг 3: Настройка Global Volume (URP)
1. В Setup Helper нажмите `Настроить URP Volume эффекты`
2. Система автоматически найдет или создаст Global Volume
3. Настроит динамические цветовые эффекты

### Шаг 4: Финальные настройки
1. В `Window → Rendering → Lighting Settings` установите новый материал как `Skybox Material`
2. Убедитесь что Environment Lighting Source установлен в `Color`
3. Протестируйте переходы дня и ночи

## Оптимизация для платформ

### Мобильные устройства
- Нажмите `Оптимизировать для мобильных` в Setup Helper
- Уменьшенная плотность звезд (60-80)
- Быстрые переходы цветов
- Упрощенные эффекты тумана

### ПК/WebGL
- Нажмите `Настроить для ПК (высокое качество)`
- Увеличенная плотность звезд (до 120)
- Медленные плавные переходы
- Расширенные атмосферные эффекты

## Особенности нового шейдера

### Автоматическое управление звездами
Звезды теперь **автоматически** появляются только ночью на основе яркости неба:
- Нет необходимости в ручной настройке видимости
- Плавное появление и исчезновение
- Реалистичное мерцание

### Атмосферная теплота
- **Warmth Factor** контролирует теплоту/прохладу атмосферы
- Положительные значения = теплые тона (дневная атмосфера)
- Отрицательные значения = холодные тона (ночная атмосфера)

### Мобильная оптимизация
- Упрощенные расчеты звезд (2D проекция вместо 3D)
- Один проход на ячейку сетки
- Оптимизированные хеш-функции
- Target 2.0 совместимость

## Устранение неполадок

### Звезды не появляются
- Убедитесь что используется новый шейдер `AtmosphericSkyboxMobile`
- Проверьте что Star Brightness > 0
- Время должно быть ночным (определяется автоматически)

### Слишком яркие/темные переходы
- Настройте URP Volume параметры через URPVolumeController
- Измените Brightness Day/Night значения
- Проверьте Ambient Intensity в атмосферных настройках

### Производительность на мобильных
- Уменьшите Star Density до 40-60
- Отключите Star Twinkle (установите в 0)
- Используйте `Оптимизировать для мобильных` в Setup Helper
