# Заметки об обновлении до v2.0

## Критические изменения

### 1. Интеграция с ActionScheduler

FishingSystem теперь **реализует интерфейс IAction**. Это означает:

✅ **Что работает автоматически:**
- Рыбалка блокирует движение и атаку
- При попытке движения (WASD, клик по NavMesh) рыбалка отменяется
- При попытке атаки рыбалка отменяется
- ActionScheduler автоматически управляет приоритетами действий

⚠️ **Что нужно настроить:**
- В FishingSystem добавлено поле `Action Scheduler`
- Оно находится автоматически через `GetComponent<ActionScheduler>()`
- Но можно назначить вручную в инспекторе для надежности

### 2. Улучшенная отмена рыбалки

Метод `Cancel()` теперь:
- Останавливает все корутины
- Останавливает мини-игру если активна
- Очищает все визуальные элементы (удочка, анимации)
- Очищает UI полностью
- Показывает кнопку снова если игрок в зоне

### 3. Новые возможности мини-игры

FishingMiniGame теперь поддерживает:
- `canFail` - возможность провала (по умолчанию false)
- `failThreshold` - порог провала
- `StopMiniGame()` - остановка без завершения

## Миграция с v1.0

### Шаг 1: Обновите FishingSystem
1. Откройте префаб игрока
2. Найдите компонент FishingSystem
3. Убедитесь, что поле `Action Scheduler` заполнено (или оставьте пустым - найдется автоматически)

### Шаг 2: Проверьте работу
1. Запустите игру
2. Начните рыбалку
3. Попробуйте:
   - Нажать WASD - рыбалка должна отмениться
   - Кликнуть по NavMesh - рыбалка должна отмениться
   - Кликнуть по врагу - рыбалка должна отмениться
   - Выйти из зоны - рыбалка должна отмениться

### Шаг 3: Настройте провал (опционально)
Если хотите, чтобы игрок мог провалить мини-игру:
1. Откройте FishingMiniGame в инспекторе
2. Включите `Can Fail`
3. Установите `Fail Threshold` (например, 0 или -0.5)

## Изменения в коде

### Если вы вызывали CancelFishing() в своем коде:

**Старый код:**
```csharp
fishingSystem.CancelFishing();
```

**Новый код (рекомендуется):**
```csharp
fishingSystem.Cancel(); // Через интерфейс IAction
```

**Или (работает тоже):**
```csharp
fishingSystem.CancelFishing(); // Вызывает Cancel() внутри
```

### Если вы подписывались на события:

События остались те же:
- `OnFishingComplete` - рыба поймана
- `OnFishingFailed` - рыба сорвалась

Но теперь `OnFishingFailed` вызывается также:
- При пропуске окна подсечки
- При провале мини-игры (если включено)

## Отладка проблем

### Рыбалка не отменяется при движении

**Проверьте:**
1. FishingSystem реализует IAction ✓
2. ActionScheduler назначен в FishingSystem
3. Mover тоже реализует IAction
4. В консоли появляется "Рыбалка отменена"

**Решение:**
```csharp
// В FishingSystem должно быть:
public class FishingSystem : MonoBehaviour, IAction
{
    [SerializeField] private ActionScheduler actionScheduler;
    
    private void Awake()
    {
        if (actionScheduler == null)
        {
            actionScheduler = GetComponent<ActionScheduler>();
        }
    }
    
    public void Cancel()
    {
        // ... код отмены
    }
}
```

### Игрок не может двигаться после рыбалки

**Проверьте:**
1. EndFishing() вызывает `actionScheduler.CancelCurrentAction()`
2. Cancel() НЕ вызывает `actionScheduler.CancelCurrentAction()` (это вызовет рекурсию)

**Решение:**
```csharp
private void EndFishing(bool success)
{
    // ... очистка
    
    // Освобождаем ActionScheduler
    if (actionScheduler != null)
    {
        actionScheduler.CancelCurrentAction();
    }
}

public void Cancel()
{
    // ... очистка
    
    // НЕ вызываем actionScheduler.CancelCurrentAction() здесь!
    // Cancel() вызывается самим ActionScheduler
}
```

### Бесконечная рекурсия

Если видите StackOverflowException:

**Причина:** Cancel() вызывает actionScheduler.CancelCurrentAction(), который снова вызывает Cancel()

**Решение:** Уберите вызов actionScheduler.CancelCurrentAction() из Cancel()
