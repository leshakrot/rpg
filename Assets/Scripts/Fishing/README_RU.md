# Улучшенная система рыбалки

## Что изменилось

Система рыбалки теперь работает в несколько этапов и **полностью интегрирована с системой действий игрока**:

### 1. Начало рыбалки
- Игрок входит в зону рыбалки
- Появляется кнопка **"Ловить рыбу"**
- При нажатии:
  - В руке появляется удочка
  - Анимация меняется на "Idle Fishing" (ожидание)
  - **Блокируется движение и атака** (через ActionScheduler)
  - Появляется кнопка **"Отменить"** (не блокирует клики по миру)
  - Начинается ожидание поклевки (3-8 секунд)

### 2. Поклевка
- Через случайное время происходит поклевка
- Воспроизводится звук клева
- Появляется кнопка **"Подсечь"**
- У игрока есть **3 секунды** чтобы нажать кнопку
- Если не успел - рыба срывается

### 3. Подсечка
- Игрок нажимает **"Подсечь"**
- Анимация меняется на "Fishing" (активная ловля)
- Появляется панель мини-игры
- Кнопка меняется на **"Тянуть"**

### 4. Ловля
- Игрок удерживает кнопку **"Тянуть"** или клавишу **Пробел**
- Нужно удерживать иконку рыбы в целевой зоне
- При успехе - рыба добавляется в инвентарь
- При провале - рыба срывается

## Отмена рыбалки

Рыбалка **автоматически отменяется** в следующих случаях:

1. **Игрок начинает движение** (WASD или клик по NavMesh)
   - ActionScheduler автоматически отменяет рыбалку
   - Удочка исчезает, анимации сбрасываются
   - Управление восстанавливается
   - **Работает с ПЕРВОГО клика** (клики проходят сквозь кнопки "Отменить" и "Тянуть")

2. **Игрок нажимает кнопку "Отменить"** (во время ожидания поклевки)
   - Явная отмена рыбалки
   - Возврат в обычное состояние

3. **Игрок начинает атаку** (клик по врагу)
   - ActionScheduler автоматически отменяет рыбалку
   - Игрок переходит в режим боя

4. **Игрок выходит из зоны рыбалки**
   - Рыбалка отменяется принудительно
   - Кнопка скрывается

5. **Время на подсечку истекло**
   - Рыба срывается
   - Показывается уведомление о провале

**Важно:** Кнопка "Подсечь" **НЕ пропускает клики** - это намеренно! У игрока есть только 3 секунды на подсечку, и случайный клик по миру не должен отменять рыбалку.

## Управление

### Клавиатура
- **Пробел** - Тянуть удочку (можно удерживать)
- **WASD** - Отменить рыбалку и начать движение
- **Клик по NavMesh** - Отменить рыбалку и идти к точке

### UI кнопки
- **"Ловить рыбу"** - Начать рыбалку
- **"Отменить"** - Отменить рыбалку во время ожидания (клики по миру тоже работают!)
- **"Подсечь"** - Подсечь рыбу (появляется только во время поклевки, блокирует клики по миру!)
- **"Тянуть"** - Тянуть удочку (можно удерживать, клики по миру отменяют рыбалку)

## Быстрая настройка

### Шаг 1: Настройка FishingSystem
В инспекторе компонента FishingSystem назначьте:
1. **Player Animator** - Animator игрока
2. **Fishing Rod Prefab** - Префаб удочки (см. ниже как создать)
3. **Right Hand Transform** - Transform правой руки из скелета игрока
4. **Action Scheduler** - ActionScheduler компонент игрока (обычно находится автоматически)
5. **Bite Sound** - Звук поклевки (AudioClip)
6. **Audio Source** - AudioSource компонент

### Шаг 2: Создание удочки
1. В меню Unity: `GameObject → 3D Object → Simple Fishing Rod`
2. Настройте позицию и поворот удочки
3. Создайте префаб: перетащите объект в папку Prefabs
4. Назначьте префаб в FishingSystem

### Шаг 3: Настройка анимаций
В Animator Controller игрока добавьте:

**Параметры:**
- `IsFishing` (Bool) - ожидание поклевки
- `IsCatching` (Bool) - активная ловля

**Переходы:**
- Idle → Idle Fishing (когда IsFishing = true)
- Idle Fishing → Fishing (когда IsCatching = true)
- Fishing → Idle (когда IsFishing = false)

### Шаг 4: Настройка FishingUI
В инспекторе FishingUI добавьте ссылку на:
- **Fishing Mini Game** - компонент FishingMiniGame

### Шаг 5: Настройка FishingMiniGame (опционально)
В инспекторе FishingMiniGame можно настроить:
- **Can Fail** - Может ли игрок провалить мини-игру (по умолчанию false)
- **Fail Threshold** - Порог провала (если прогресс падает до этого значения)

## Технические детали

### Интеграция с ActionScheduler

FishingSystem реализует интерфейс `IAction`, что означает:
- При начале рыбалки она регистрируется как текущее действие
- Любое другое действие (движение, атака) автоматически отменяет рыбалку
- При завершении/отмене рыбалки ActionScheduler освобождается

### Состояния системы
```
Idle → WaitingForBite → Biting → Catching → Idle
       ↓ (отмена)        ↓ (отмена)  ↓ (отмена)
       Idle              Idle         Idle
```

### Параметры времени
- **Min Bite Time**: 3 сек (минимальное время до поклевки)
- **Max Bite Time**: 8 сек (максимальное время до поклевки)
- **Bite Window Duration**: 3 сек (время на подсечку)

### События
- `OnFishingComplete` - рыба поймана
- `OnFishingFailed` - рыба сорвалась

## Отладка

Включите Console в Unity для просмотра сообщений:
- "Заброс удочки..." - рыбалка началась
- "Ожидание поклевки..." - ждем поклевки
- "Поклевка!" - нужно подсечь
- "Подсечка!" - начинается ловля
- "Не успели подсечь!" - пропустили окно
- "Поймана рыба" - успех
- "Рыба сорвалась" - провал
- "Рыбалка отменена" - игрок отменил действие

## Частые проблемы

**Удочка не появляется:**
- Проверьте, что назначен префаб удочки
- Проверьте, что назначен Transform правой руки

**Анимации не работают:**
- Проверьте параметры в Animator Controller
- Убедитесь, что назначен Player Animator

**Кнопка "Подсечь" не появляется:**
- Проверьте Debug.Log - происходит ли поклевка
- Убедитесь, что InteractButton назначен в FishingUI

**Звук не воспроизводится:**
- Проверьте, что назначен AudioClip
- Проверьте, что есть AudioSource компонент
- Проверьте громкость AudioSource

**Рыбалка не отменяется при движении:**
- Проверьте, что назначен Action Scheduler в FishingSystem
- Убедитесь, что FishingSystem реализует IAction
- Проверьте, что Mover тоже реализует IAction

**Игрок не может двигаться после рыбалки:**
- Проверьте, что EndFishing() вызывает actionScheduler.CancelCurrentAction()
- Убедитесь, что Cancel() не вызывает бесконечную рекурсию
