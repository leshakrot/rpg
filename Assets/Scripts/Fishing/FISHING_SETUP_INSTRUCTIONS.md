# Инструкция по настройке улучшенной системы рыбалки

## Обзор изменений

Система рыбалки была улучшена и теперь включает следующие этапы:

1. **Начало рыбалки** - игрок нажимает кнопку "Ловить рыбу"
   - Появляется удочка в руке
   - Анимация переключается на "Idle Fishing"
   - Начинается ожидание поклевки

2. **Поклевка** - через случайное время (3-8 секунд)
   - Воспроизводится звук поклевки
   - Появляется кнопка "Подсечь"
   - У игрока есть 3 секунды на подсечку

3. **Подсечка** - игрок нажимает "Подсечь"
   - Анимация меняется на "Fishing" (активная ловля)
   - Появляется панель мини-игры
   - Кнопка меняется на "Тянуть"

4. **Ловля** - игрок удерживает кнопку "Тянуть" или пробел
   - Мини-игра активна
   - При успехе - рыба добавляется в инвентарь
   - При провале - рыба срывается

## Настройка компонентов

### 1. FishingSystem

Добавьте следующие поля в инспекторе:

- **Player Animator** - Animator компонент игрока
- **Fishing Rod Prefab** - Префаб удочки (создайте 3D модель удочки)
- **Right Hand Transform** - Transform правой руки игрока (обычно находится в иерархии скелета)
- **Min Bite Time** - Минимальное время до поклевки (по умолчанию 3 сек)
- **Max Bite Time** - Максимальное время до поклевки (по умолчанию 8 сек)
- **Bite Window Duration** - Время на подсечку (по умолчанию 3 сек)
- **Bite Sound** - AudioClip звука поклевки
- **Audio Source** - AudioSource компонент для воспроизведения звуков

### 2. Animator Controller

Добавьте в Animator Controller игрока следующие параметры:

- **IsFishing** (Bool) - true когда игрок в режиме ожидания поклевки
- **IsCatching** (Bool) - true когда игрок активно ловит рыбу

Создайте анимации:
- **Idle Fishing** - игрок стоит с удочкой, ожидает поклевки
- **Fishing** - игрок активно тянет удочку

Настройте переходы:
- Idle → Idle Fishing (условие: IsFishing == true)
- Idle Fishing → Fishing (условие: IsCatching == true)
- Fishing → Idle (условие: IsFishing == false)

### 3. Создание префаба удочки

1. Создайте 3D модель удочки или используйте готовую
2. Создайте префаб из модели
3. Настройте позицию и поворот так, чтобы удочка правильно лежала в руке
4. Назначьте этот префаб в поле **Fishing Rod Prefab** компонента FishingSystem

### 4. Звук поклевки

1. Найдите или создайте звуковой эффект поклевки (например, всплеск воды)
2. Импортируйте его в проект
3. Назначьте в поле **Bite Sound** компонента FishingSystem
4. Убедитесь, что у FishingSystem есть AudioSource компонент

### 5. Настройка UI

FishingUI автоматически управляет состояниями кнопки:
- "Ловить рыбу" - при входе в зону
- "Подсечь" - во время поклевки (появляется только на время окна подсечки)
- "Тянуть" - во время активной ловли

Кнопка поддерживает как клик мышью, так и удержание для мобильных устройств.

## Управление

### Клавиатура
- **Пробел** - Тянуть удочку во время ловли (можно удерживать)

### UI кнопки
- **Ловить рыбу** - Начать рыбалку
- **Подсечь** - Подсечь во время поклевки (появляется только на 3 секунды)
- **Тянуть** - Тянуть удочку (можно удерживать кнопку)

## Состояния системы

```
FishingState.Idle
    ↓ (нажатие "Ловить рыбу")
FishingState.WaitingForBite (ожидание 3-8 сек)
    ↓ (поклевка)
FishingState.Biting (окно 3 сек для подсечки)
    ↓ (нажатие "Подсечь")
FishingState.Catching (мини-игра)
    ↓ (успех/провал)
FishingState.Idle
```

## Отладка

Используйте Debug.Log сообщения для отслеживания состояний:
- "Заброс удочки..." - начало рыбалки
- "Ожидание поклевки..." - ожидание
- "Поклевка! Нажмите кнопку для подсечки!" - поклевка
- "Подсечка! Начинаем ловлю..." - успешная подсечка
- "Не успели подсечь! Рыба сорвалась." - пропущена подсечка
- "Поймана рыба: [название]" - успешная ловля
- "Рыба сорвалась!" - провал мини-игры

## Возможные проблемы

1. **Удочка не появляется**
   - Проверьте, что назначен Fishing Rod Prefab
   - Проверьте, что назначен Right Hand Transform
   - Убедитесь, что трансформ руки правильный

2. **Анимации не переключаются**
   - Проверьте, что назначен Player Animator
   - Убедитесь, что в Animator Controller есть параметры IsFishing и IsCatching
   - Проверьте настройку переходов между анимациями

3. **Звук не воспроизводится**
   - Проверьте, что назначен Bite Sound
   - Убедитесь, что есть Audio Source компонент
   - Проверьте громкость Audio Source

4. **Кнопка "Подсечь" не появляется**
   - Проверьте, что InteractButton назначен в FishingUI
   - Убедитесь, что поклевка происходит (смотрите Debug.Log)
   - Проверьте, что кнопка не скрыта другими UI элементами
