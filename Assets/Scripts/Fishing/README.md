# Улучшенная система рыбалки

## Обзор изменений

Система рыбалки была полностью переработана с добавлением следующих возможностей:

### 1. **Система данных рыб (FishData)**
- Создан ScriptableObject для настройки каждого вида рыбы
- Каждый предмет имеет **индивидуальную сложность** и вес выпадения
- Можно добавить несколько предметов с разной сложностью в один FishData
- Система весов для редкости каждого предмета

### 2. **Привязка рыб к зонам рыбалки**
- Каждая зона рыбалки (FishingAreaTrigger) имеет свой список доступных рыб
- Рыбы выбираются случайно с учетом их веса редкости
- Разные локации могут иметь разные виды рыб

### 3. **Настраиваемая сложность**
- Ползунок сложности от 0 (легко) до 1 (очень сложно)
- Влияет на скорость движения рыбы (20-120 единиц)
- Влияет на хаотичность движения (интервалы смены направления 0.3-2.5 сек)
- Визуальный индикатор сложности в редакторе

## Как использовать

### Создание новой рыбы

1. **Создайте FishData asset:**
   - ПКМ в Project → Create → Fishing → Fish Data
   - Назовите файл (например, "Salmon")

2. **Настройте параметры для каждого предмета:**
   - Нажмите "+" в списке "Possible Items"
   - Для каждого элемента настройте:
     - **Item**: Выберите InventoryItem
     - **Catch Difficulty**: Индивидуальная сложность для этого предмета (0-1)
       - 0.0: Неподвижный крючок (гарантированный улов)
       - 0.1-0.3: Легко (медленное движение)
       - 0.4-0.6: Средне (умеренная скорость)
       - 0.7-0.8: Сложно (быстрое и хаотичное движение)
       - 0.9-1.0: Экстремально сложно (максимальная скорость и хаос!)
     - **Drop Weight**: Вес выпадения этого предмета (1-100)

3. **Можно создавать разнообразные наборы:**
   - Обучающая рыба (сложность 0.0, вес 100) - для новичков
   - Легкая рыба (сложность 0.2, вес 70)
   - Средняя рыба (сложность 0.5, вес 25)
   - Легендарный трофей (сложность 1.0, вес 5) - настоящий вызов!

### Настройка зоны рыбалки

1. **Выберите объект с FishingAreaTrigger**

2. **В инспекторе найдите "Available Fish"**

3. **Добавьте FishData assets:**
   - Нажмите "+" чтобы добавить слот
   - Перетащите созданные FishData в список
   - Можно добавить одну и ту же рыбу несколько раз для увеличения шанса

### Настройка PlayerFishingSystemInteraction

**ВАЖНО:** Добавьте ссылку на FishingSystem:
- Выберите объект игрока с компонентом PlayerFishingSystemInteraction
- В инспекторе найдите поле "Fishing System"
- Перетащите объект с компонентом FishingSystem

## Технические детали

### Формулы расчета параметров

```csharp
// Специальный случай: сложность 0 = неподвижный крючок
if (difficulty == 0):
    minSpeed = 0
    maxSpeed = 0
    minInterval = 999 (не меняет направление)
    maxInterval = 999

// Квадратичная прогрессия для остальных значений
difficultySquared = difficulty * difficulty

minIconSpeed = Lerp(0, 100, difficultySquared)
maxIconSpeed = Lerp(0, 200, difficultySquared)
minDirectionChangeInterval = Lerp(3.0, 0.1, difficultySquared)
maxDirectionChangeInterval = Lerp(5.0, 0.3, difficultySquared)
```

**Примеры значений:**

| Сложность | Squared | Min Speed | Max Speed | Min Interval | Max Interval |
|-----------|---------|-----------|-----------|--------------|--------------|
| 0.0       | 0.00    | 0         | 0         | 999 сек      | 999 сек      |
| 0.2       | 0.04    | 4         | 8         | 2.92 сек     | 4.81 сек     |
| 0.5       | 0.25    | 25        | 50        | 2.28 сек     | 3.83 сек     |
| 0.7       | 0.49    | 49        | 98        | 1.58 сек     | 2.69 сек     |
| 0.9       | 0.81    | 81        | 162       | 0.65 сек     | 1.19 сек     |
| 1.0       | 1.00    | 100       | 200       | 0.1 сек      | 0.3 сек      |

**Почему квадратичная прогрессия?**
- При difficulty = 0.0: Крючок полностью неподвижен (идеально для обучения)
- При difficulty = 0.5: squared = 0.25 (умеренная сложность)
- При difficulty = 0.9: squared = 0.81 (резкий скачок сложности!)
- При difficulty = 1.0: squared = 1.0 (экстремальная скорость и хаос!)

Это создает плавную кривую на низких уровнях и драматический рост сложности на высоких.

### Система весов

Каждый предмет имеет свой вес. Система выбирает предмет на основе весовой системы:

**Пример:**
FishData с предметами:
- Карась (вес 60) - шанс 60/100 = 60%
- Окунь (вес 30) - шанс 30/100 = 30%
- Щука (вес 10) - шанс 10/100 = 10%

При этом каждый предмет будет иметь свою сложность поимки!
