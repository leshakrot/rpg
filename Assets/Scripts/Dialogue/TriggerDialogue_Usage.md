# Система триггер-диалогов

Эта система позволяет запускать диалоги автоматически при входе игрока в определенную зону.

## Основные компоненты

### AIConversant
Основной компонент диалогов, поддерживает два режима работы:
- **Стандартный режим**: диалог запускается при клике на объект
- **Триггер режим**: диалог запускается автоматически при входе в коллайдер

#### Поля триггер-диалогов:
- `isTrigger` - включает режим триггера
- `triggerOnce` - диалог срабатывает только один раз
- `showTriggerVisualization` - показывает зону триггера в Scene View
- `triggerColor` - цвет визуализации триггера

## Как создать триггер-диалог

1. Создайте GameObject с компонентом AIConversant
2. Добавьте Collider (любой тип)
3. В AIConversant отметьте флаг "Is Trigger"
4. Collider автоматически станет триггером
5. Назначьте нужный Dialogue
6. Настройте визуализацию по желанию

## Примеры использования

### Монолог персонажа при входе в зону
```
GameObject: "PlayerThoughts"
- AIConversant (isTrigger = true, triggerOnce = true)
- BoxCollider (автоматически станет isTrigger = true)
- Dialogue: содержит мысли персонажа
```

### Описание локации
```
GameObject: "LocationDescription"
- AIConversant (isTrigger = true, triggerOnce = false)
- SphereCollider (автоматически станет isTrigger = true)
- Dialogue: описание происходящего
```

### Предупреждение об опасности
```
GameObject: "DangerWarning"
- AIConversant (isTrigger = true, triggerOnce = false)
- CapsuleCollider (автоматически станет isTrigger = true)
- Dialogue: предупреждение о ловушке
```

## API для разработчиков

### AIConversant
- `ResetTrigger()` - сбрасывает состояние триггера
- `IsTrigger()` - проверяет, является ли диалог триггерным

## Автоматизация

- При включении флага `isTrigger` коллайдер автоматически становится триггером
- Визуализация зоны триггера в Scene View для удобства дизайна уровней
- Поддержка всех типов коллайдеров (Box, Sphere, Capsule)

## Интеграция с существующей системой

Новая система полностью совместима с существующими диалогами. Стандартные диалоги (с кликом) продолжают работать как раньше.

## Рекомендации

1. Для монологов и описаний используйте `triggerOnce = true`
2. Для повторяющихся предупреждений используйте `triggerOnce = false`
3. Используйте визуализацию для точной настройки зон триггеров
4. Убедитесь, что у игрока есть тег "Player"
