# Система компаньонов - Инструкция по настройке

## Быстрая настройка (15 минут)

### 1. Создайте данные компаньона
`ПКМ > Create > Companions > Companion Data`

Заполните:
- **Companion Name**: "Наемник"
- **Hire Cost**: 100
- **Follow Distance**: 3
- **Combat Range**: 10

### 2. Настройте NPC-компаньона

Возьмите любую модель персонажа и добавьте компоненты:
- `NavMeshAgent` (Speed: 3.5, Radius: 0.5, Height: 2) ⚠️ **ОТКЛЮЧИТЕ**
- `CompanionController` ⚠️ **ОТКЛЮЧИТЕ этот компонент** (снимите галочку)
- `CompanionRecruiter` (укажите ваш CompanionData)
- `CompanionPredicates`
- `AIConversant`
- `Fighter` (назначьте оружие)
- `Health`
- `BaseStats`
- `ActionScheduler`

**Важно:** 
- CompanionController и NavMeshAgent должны быть **выключены** по умолчанию
- Они включатся автоматически при найме
- Компаньон нанимает сам себя через диалог

### 3. Создайте диалог

`ПКМ > Create > Dialogue` → откройте в Dialogue Editor

**Структура диалога:**

```
Root → проверка условий
  ├─ "Не нанят" (условие: CompanionNotHired)
  │   ├─ "Нанять за 100 золотых" (условие: CanAffordCompanion, действие: hire_companion)
  │   └─ "Отказаться"
  │
  ├─ "Активен" (условие: CompanionActive)
  │   ├─ "Отправить на базу" (действие: dismiss_companion)
  │   └─ "Продолжить"
  │
  └─ "На базе" (условие: CompanionOnBase)
      ├─ "Вызвать обратно" (действие: call_companion)
      └─ "Оставить"
```

Назначьте диалог в AIConversant компаньона.

### 4. Проверьте NavMesh

`Window > AI > Navigation > Bake`

Если NavMesh не запечен - выберите статичные объекты, отметьте Navigation Static и нажмите Bake.

## Готово!

Теперь можно:
- Поговорить с компаньоном и нанять его (списываются деньги)
- Компаньон следует за игроком
- Компаньон атакует врагов
- Враги атакуют компаньона
- Отправить на базу / вызвать обратно
- Переходить между сценами - компаньон сохраняется

## Условия для диалогов

- `CompanionNotHired` - компаньон не нанят
- `CompanionHired` - компаньон нанят
- `CompanionActive` - следует за игроком
- `CompanionOnBase` - на базе (не активен)
- `CanAffordCompanion` - достаточно денег
- `CannotAffordCompanion` - недостаточно денег

## Действия для диалогов

- `hire_companion` - нанять
- `dismiss_companion` - отправить на базу
- `call_companion` - вызвать обратно

## Частые проблемы

**Компаньон не появляется после найма:**
- Проверьте что у компаньона включен CompanionController
- Проверьте консоль на ошибки

**Компаньон не следует:**
- Проверьте что NavMesh запечен
- Проверьте настройки NavMeshAgent

**Компаньон не атакует:**
- Проверьте что у Fighter назначено оружие
- Проверьте Combat Range в CompanionController

**Компаньон следует за игроком до найма:**
- Проверьте что CompanionController **выключен** (галочка снята в Inspector)
- Он должен включиться только после найма

**Враги не атакуют компаньона:**
- Проверьте что компаньон нанят (CompanionController включен)
- После найма компаньон получает тег "Player"
- Проверьте что у компаньона есть Health компонент

**Диалог не работает:**
- Проверьте что Action ID совпадают
- Проверьте что CompanionPredicates добавлен на компаньона
