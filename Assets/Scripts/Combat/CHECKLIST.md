## Типичные проблемы и решения

### Проблема: "Type could not be found"
**Решение**: Убедитесь что имя типа написано правильно (case-sensitive), например `QuestProgress` а не `questProgress`

### Проблема: Враг спавнится без компонента
**Решение**: Проверьте что `Use Dynamic Spawn` включен и компонент добавлен в `Components To Add`

### Проблема: Компонент добавлен, но не настроен
**Решение**: Настройте `On Component Added` event с методом типа `SetupQuestProgress`

### Проблема: Враг не спавнится вообще
**Решение**: 
1. Включите `Show Debug Info` в EnemySpawner
2. Проверьте консоль - там будет сообщение почему точка пропущена
3. Убедитесь что условие возвращает `canSpawn = true`

## Примеры готовых конфигураций

### Конфигурация 1: Простой квестовый враг
```
GameObject: SpawnPoint
  ✓ Use Dynamic Spawn
  
  Spawn Condition:
    [0] DynamicSpawnHelper.CheckQuestActive
        - questList: [ваш QuestList]
        - quest: [ваш Quest]
  
  Components To Add:
    [0] Component Type Name: "QuestProgress"
        On Component Added:
          [0] DynamicSpawnHelper.SetupQuestProgress
              - questList: [ваш QuestList]
              - questReference: [ваш Quest]
              - objectiveReference: "kill_enemies"
              - amount: 1
          [1] DynamicSpawnHelper.ConnectQuestProgressToHealth
```

### Конфигурация 2: Зона для продвинутых игроков
```
GameObject: SpawnZone
  ✓ Use Conditional Spawn
  
  Zone Spawn Condition:
    [0] SpawnConditionExamples.CheckPlayerLevel
        - minLevel: 10
```

### Конфигурация 3: Босс после выполнения цели
```
GameObject: SpawnPoint (Boss)
  ✓ Use Dynamic Spawn
  
  Spawn Condition:
    [0] DynamicSpawnHelper.CheckQuestCondition
        - questList: [ваш QuestList]
        - quest: [ваш Quest]
        - objectiveReference: "kill_all_minions"
        - amount: 0
    [1] DynamicSpawnHelper.InvertCondition
```
