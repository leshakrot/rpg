📌 ЧТО ЭТО ДАЕТ?

Теперь вы можете:
✓ Добавлять компоненты на врагов автоматически при спавне
✓ Настраивать все поля компонента прямо в SpawnPoint Inspector
✓ Привязывать методы к событиям (например, вызвать метод при смерти врага)
✓ Использовать условия для спавна (квесты, диалоги и т.д.)

═══════════════════════════════════════════════════════════════════════════════

🚀 БЫСТРЫЙ СТАРТ (4 простых шага)

1️⃣ СОЗДАЙТЕ ШАБЛОН КОМПОНЕНТА
   
   На любом GameObject в сцене:
   - Добавьте нужный компонент (например, QuestProgress)
   - Настройте все его поля (Quest List, Amount и т.д.)
   - Этот компонент станет шаблоном

2️⃣ ОТКРОЙТЕ SPAWN POINT В INSPECTOR
   
   Выберите GameObject с компонентом SpawnPoint
   (например, /Enemy Spawner/Grunt Spawn Point)

3️⃣ ДОБАВЬТЕ КОМПОНЕНТ В СПИСОК
   
   В разделе "Условный спавн и динамические компоненты"
   → Нажмите "+" в списке "Динамические компоненты"
   → Разверните новый элемент

4️⃣ ПЕРЕТАЩИТЕ ШАБЛОН И НАСТРОЙТЕ
   
   ┌──────────────────────────────────────────────────┐
   │ Component Template:  [Перетащите компонент сюда] │
   │                      ↑                           │
   │          Перетащите компонент из Hierarchy       │
   │          или Project (с настроенными полями)     │
   ├──────────────────────────────────────────────────┤
   │ Template Component Settings:                     │
   │   Quest List:     [My Quest]                     │
   │   Amount:         1                              │
   │   ... (все поля компонента редактируются!)       │
   ├──────────────────────────────────────────────────┤
   │ Event Binding:                                   │
   │   Event Type:    OnDie                           │
   │   Method Name:   AddProgress                     │
   │                  ↑                               │
   │          имя public метода без параметров        │
   └──────────────────────────────────────────────────┘

═══════════════════════════════════════════════════════════════════════════════

💡 ЧТО ПРОИЗОЙДЕТ?

Когда враг заспавнится:
→ На него добавится компонент QuestProgress
→ Все поля будут скопированы из шаблона (Quest List, Amount и т.д.)
→ В Health.onDie автоматически добавится вызов QuestProgress.AddProgress()
→ При смерти врага квест обновится!

📋 ВАЖНЫЕ ПРАВИЛА

✅ Component Template:
   • Перетащите КОМПОНЕНТ (не GameObject!)
   • Можно взять из любого GameObject в Hierarchy
   • Можно взять из префаба в Project
   • Все поля компонента можно редактировать прямо в Inspector!
   
✅ Редактирование полей:
   • Разверните элемент в списке
   • Увидите "Template Component Settings"
   • Редактируйте поля как обычно
   • Изменения сохраняются автоматически
   
✅ Method Name:
   • Метод должен быть public
   • Метод без параметров: public void AddProgress() { }
   • Точное совпадение имени!

🔧 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

❌ Не вижу раздел "Условный спавн" в Inspector?
   → File → Exit → перезапустите Unity полностью

❌ Компонент не добавляется на врага?
   → Проверьте Component Type Name (регистр важен!)
   → Включите showDebugInfo в EnemySpawner
   → Смотрите Console для сообщений

❌ Метод не вызывается при смерти?
   → Проверьте что метод public
   → Проверьте что метод без параметров
   → Проверьте точное совпадение Method Name

❌ Враг вообще не спавнится?
   → Проверьте Spawn Chance (должен быть > 0)
   → Проверьте что в списке врагов есть префаб
   → Временно уберите Condition (если используется)
