# Система спавна врагов

Эта система позволяет создавать динамический спавн врагов на сценах игры. При переходе на новую сцену или возвращении на старую сцену, система автоматически создает врагов в заданных точках спавна.

## Основные компоненты

### 1. EnemySpawner
Главный компонент системы спавна. На каждой сцене должен быть только один экземпляр этого объекта.

**Функции:**
- Управление спавном врагов при загрузке сцены
- Респавн врагов при возвращении на сцену
- Сохранение/загрузка состояния системы
- Визуализация связей между спавнером и врагами

**Настройки:**
- `Мин. гарантированных врагов` - минимальное количество врагов, которое гарантированно появится на сцене
- `Макс. врагов на сцене` - ограничение на общее количество врагов
- `Респавн при возвращении` - если включено, враги будут респавниться при повторном входе на сцену
- `Задержка респавна` - задержка перед спавном врагов после загрузки сцены
- `Использовать зоны спавна` - если включено, враги будут спавниться с учетом настроек зон
- `Макс. врагов на зону` - максимальное количество врагов в одной зоне
- `Показывать отладочный вывод` - вывод информации о спавне в консоль
- `Отрисовывать линии к врагам` - визуализация связей между спавнером и созданными врагами

### 2. SpawnPoint
Точка спавна врагов. Размещается в местах, где должны появляться враги.

**Настройки:**
- `Список врагов` - префабы врагов, которые могут спавниться в этой точке
- `Радиус спавна` - область вокруг точки, в которой могут появиться враги
- `Шанс спавна` - вероятность появления врага в этой точке (от 0 до 1)
- `Всегда показывать Gizmo` - отображение визуального представления точки даже когда она не выбрана
- `Цвет точки` - настройка цвета визуализации точки

### 3. SpawnZone
Зона спавна, которая объединяет несколько точек спавна в группу с общими настройками.

**Режимы спавна:**
- `Random` - случайное количество врагов на основе коэффициента активации
- `Exact` - точное заданное количество врагов
- `RandomRange` - случайное количество врагов в заданном диапазоне

**Настройки:**
- `Название зоны` - название для идентификации зоны
- `Цвет зоны` - цвет для визуализации зоны в редакторе
- `Размер зоны` - размер зоны спавна
- `Режим спавна` - способ определения количества активных точек
- `Коэффициент активации` - процент точек в зоне, которые будут активны (для режима Random)
- `Точное количество врагов` - фиксированное число врагов (для режима Exact)
- `Минимум врагов` и `Максимум врагов` - диапазон (для режима RandomRange)
- `Настройки визуализации` - параметры отображения зоны и информации о ней

## Как использовать

### Настройка системы:

1. Создайте объект **Enemy Spawner** через меню `RPG -> Create -> Enemy Spawner`
2. Разместите **точки спавна** через меню `RPG -> Create -> Enemy Spawn Point` или создайте **зоны спавна** через `RPG -> Create -> Spawn Zone`
3. Для каждой точки спавна добавьте префабы врагов, которые могут в ней появляться
4. Если используете зоны, вы можете автоматически создать точки внутри зоны, используя кнопки в инспекторе зоны
5. Выберите подходящий режим спавна для каждой зоны

### Инструменты редактора:

- **Выбор точек без врагов** - позволяет быстро найти точки, которым не назначены враги
- **Копирование врагов между точками** - копирует список врагов из одной точки во все остальные точки в зоне
- **Тестовый спавн** - позволяет проверить спавн врагов в режиме игры
- **Визуализация** - настраиваемое отображение точек, зон и связей между ними

### Рекомендации по настройке:

1. **Зоны спавна** лучше использовать в больших открытых областях, где нужно контролировать плотность врагов
2. **Отдельные точки спавна** подходят для конкретных мест, где должны появляться определенные враги
3. В зависимости от игровой ситуации выбирайте подходящий режим спавна:
   - `Random` - для общих областей с вариативной сложностью
   - `Exact` - для четко сбалансированных участков с заданной сложностью
   - `RandomRange` - для создания вариативного, но контролируемого опыта

### Интеграция с системой сохранения:

Система автоматически интегрируется с существующей системой сохранения игры. Враги, созданные спавнером, будут сохраняться между загрузками сцен и игровыми сессиями.

## Отладка и визуализация:

1. Включите `Показывать отладочный вывод` для детальной информации о процессе спавна в консоли
2. Используйте `Отрисовывать линии к врагам` для визуального отслеживания созданных врагов в игровом режиме
3. Настройте цвета и параметры отображения для лучшей видимости в редакторе

## Важные примечания:

1. Компонент `SaveableEntity` автоматически добавляется к созданным врагам
2. При смене сцен враги автоматически уничтожаются и создаются новые
3. В редакторе активные/занятые точки отображаются красным цветом, свободные - зеленым
4. Для тестирования спавна в режиме игры используйте кнопку "Тест спавна врагов" в инспекторе EnemySpawner
5. Каждая зона может использовать свой собственный режим спавна, что позволяет комбинировать разные подходы
