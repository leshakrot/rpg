# Система спавна врагов

Данная система предназначена для автоматического создания врагов на сцене. Она позволяет настраивать спавн врагов как в отдельных точках, так и в специальных зонах.

## Основные компоненты

### 1. EnemySpawner

Главный компонент, отвечающий за логику создания врагов. Основные параметры:

- **Min Guaranteed Spawns** - минимальное гарантированное количество врагов на сцене.
- **Max Enemies Per Scene** - максимальное количество врагов на сцене.
- **Respawn On Revisit** - если включено, враги будут респавниться при повторном посещении сцены.
- **Respawn Delay** - задержка перед спавном врагов после загрузки сцены.

#### Настройки зон спавна
- **Use Spawn Zones** - использовать зоны для спавна вместо отдельных точек.
- **Max Enemies Per Zone** - максимальное количество врагов в одной зоне.

#### Автолевелинг врагов
- **Use Auto Leveling** - включает автоматическую настройку уровня врагов в соответствии с уровнем игрока.
- **Min Level Offset** - минимальное отклонение от уровня игрока (может быть отрицательным для более слабых врагов).
- **Max Level Offset** - максимальное отклонение от уровня игрока (для более сильных врагов).

#### Отладка
- **Show Debug Info** - выводит подробную информацию о процессе спавна в консоль.
- **Draw Lines In Game** - отображает линии от спавнера к созданным врагам (только в режиме игры).
- **Debug Line Color** - цвет линий для визуализации.

### 2. SpawnPoint

Компонент, определяющий точку появления врагов. Параметры:

- **Enemy Prefabs** - список префабов врагов для этой точки.
- **Spawn Radius** - радиус области спавна вокруг точки.
- **Spawn Chance** - вероятность появления врага в этой точке.
- **Random Rotation** - настройки случайного поворота врага при спавне.

### 3. SpawnZone

Компонент для определения зон спавна. Зона может содержать несколько точек спавна и имеет дополнительные параметры:

- **Zone Type** - тип зоны (Rectangle, Sphere, Custom).
- **Spawn Mode** - режим активации точек спавна (All, Random, Progressive).
- **Activation Rate** - процент точек, которые будут активированы в режиме Random.

## Использование

1. Добавьте на сцену пустой объект и прикрепите к нему компонент `EnemySpawner`.
2. Создайте точки спавна с помощью инструмента "Create > RPG > Combat > Enemy Spawn Point" или через контекстное меню в иерархии.
3. Для каждой точки спавна добавьте префабы врагов, которые должны появляться в этой точке.
4. При необходимости создайте и настройте зоны спавна с помощью инструмента "Create > RPG > Combat > Spawn Zone".
5. Для настройки уровня врагов в соответствии с уровнем игрока включите опцию "Use Auto Leveling" и настройте параметры смещения уровня.

## Особенности автолевелинга

Система автоматического выравнивания уровней врагов работает следующим образом:

1. При спавне каждого врага система определяет текущий уровень игрока.
2. Вычисляется случайное смещение от уровня игрока в диапазоне от `Min Level Offset` до `Max Level Offset`.
3. Уровень врага устанавливается как "уровень игрока + смещение" (не менее 1).
4. Уровень врага устанавливается в поле `startingLevel` компонента `BaseStats`.

Это позволяет создавать врагов, соответствующих по силе текущему прогрессу игрока, с небольшими вариациями для поддержания разнообразия и баланса сложности.

## Отладка и тестирование

1. Включите опцию `Show Debug Info` для вывода подробной информации о спавне в консоль.
2. Используйте `Draw Lines In Game` для визуализации связей между спавнером и созданными врагами.
3. В режиме игры можно использовать кнопку "Тест спавна врагов" в инспекторе EnemySpawner для принудительного перезапуска процесса спавна.
