===========================================
СИСТЕМА УСЛОВНОГО СПАВНА ВРАГОВ
===========================================

ОБЗОР
-----
Система спавна врагов расширена для поддержки:
1. Условного спавна через предикаты (квесты, диалоги и т.д.)
2. Динамического добавления компонентов на врагов
3. Программного создания временных врагов
4. Автоматического управления памятью

===========================================
ОСНОВНЫЕ КОМПОНЕНТЫ
===========================================

1. EnemySpawner (обновлен)
   - Проверка условий спавна
   - Добавление динамических компонентов
   - Методы для программного спавна
   - Управление временными врагами

2. SpawnPoint (обновлен)
   - Поле spawnConditions (Condition)
   - Список componentsToAdd
   - Методы проверки условий

3. ComponentToAdd (новый класс)
   - componentPrefab - компонент для добавления
   - eventBinding - привязка к событиям

4. ComponentEventBinding (новый класс)
   - eventType - тип события (OnDie)
   - methodName - имя метода для вызова

===========================================
НАСТРОЙКА КВЕСТОВОГО ВРАГА
===========================================

ШАГ 1: Настройка SpawnPoint
---------------------------
1. Выберите SpawnPoint в сцене
2. В разделе "Условный спавн":
   - Добавьте Condition
   - Настройте предикат (например, HasQuest)

ШАГ 2: Создание QuestProgress
-----------------------------
1. Создайте GameObject в сцене
2. Добавьте компонент QuestProgress
3. Настройте:
   - Quest List (ссылка на список квестов)
   - Quest Reference (какой квест)
   - Objective Reference (какая цель)
   - Amount (сколько прогресса, обычно 1)

ШАГ 3: Привязка компонента
--------------------------
1. В SpawnPoint, раздел "Динамические компоненты"
2. Добавьте элемент:
   - Component Prefab = QuestProgress (из шага 2)
   - Event Type = OnDie
   - Method Name = AddProgress

РЕЗУЛЬТАТ: При смерти враг обновит прогресс квеста!

===========================================
ПРОГРАММНЫЙ СПАВН
===========================================

ПРОСТОЙ СПАВН
-------------
EnemySpawner spawner = FindObjectOfType<EnemySpawner>();
GameObject enemy = spawner.SpawnDynamicEnemy(
    position,
    enemyPrefab,
    OnEnemySpawned  // опциональный callback
);

СПАВН С КОМПОНЕНТАМИ
-------------------
List<ComponentToAdd> components = new List<ComponentToAdd>
{
    new ComponentToAdd
    {
        componentPrefab = questProgressPrefab,
        eventBinding = new ComponentEventBinding
        {
            eventType = ComponentEventBinding.EventType.OnDie,
            methodName = "AddProgress"
        }
    }
};

GameObject enemy = spawner.SpawnDynamicEnemyWithComponents(
    position,
    enemyPrefab,
    components,
    OnEnemySpawned
);

===========================================
ГОТОВЫЕ КОМПОНЕНТЫ
===========================================

RandomEncounterTrigger
---------------------
Компонент для создания случайных встреч:
- Настройка вероятности встречи
- Время восстановления (cooldown)
- Радиус спавна
- Опциональная привязка к квестам

ИСПОЛЬЗОВАНИЕ:
1. Создайте пустой GameObject
2. Добавьте Box Collider (Is Trigger = true)
3. Добавьте RandomEncounterTrigger
4. Настройте параметры в инспекторе

DynamicEnemySpawnExample
-----------------------
Примеры использования API:
- SpawnQuestEnemy() - квестовый враг
- SpawnRandomEncounter() - случайная встреча

===========================================
УПРАВЛЕНИЕ ПАМЯТЬЮ
===========================================

АВТОМАТИЧЕСКАЯ ОЧИСТКА
---------------------
- Динамические враги удаляются при смерти
- Трупы удаляются через corpseRemovalTime
- Используется список conditionalEnemies

ОПТИМИЗАЦИЯ
-----------
1. Настройте maxEnemiesPerScene
2. Используйте corpseRemovalTime (рекомендуется 10-15 сек)
3. Для временных врагов отключите respawnDeadEnemies

ОТЛАДКА
-------
Включите showDebugInfo в EnemySpawner для логов:
- Проверка условий
- Добавление компонентов
- Удаление врагов

===========================================
ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ
===========================================

1. КВЕСТОВЫЙ БОСС
   Условие: HasQuest("kill_boss")
   Компонент: QuestProgress
   Событие: OnDie → AddProgress

2. СЛУЧАЙНАЯ ВСТРЕЧА
   Без условий
   Без компонентов
   RandomEncounterTrigger

3. СОБЫТИЙНЫЙ СПАВН
   Условие: DialogueCompleted("event_dialogue")
   Компонент: опционально
   Программный спавн

РЕШЕНИЕ ПРОБЛЕМ

ВРАГ НЕ СПАВНИТСЯ

------------

✓ Проверьте corpseRemovalTime
✓ Используйте Memory Profiler

===========================================
ТЕХНИЧЕСКИЕ ДЕТАЛИ
===========================================

ПОДДЕРЖИВАЕМЫЕ СОБЫТИЯ
---------------------
- OnDie (Health.onDie)

ПРЕДИКАТЫ
---------
Используется система IPredicateEvaluator:
- Интеграция с квестами (QuestList)
- Интеграция с диалогами
- Интеграция с инвентарем (ItemChecker)

СОХРАНЕНИЯ
----------
- Стандартные враги сохраняются
- Динамические враги НЕ сохраняются (по дизайну)
- SpawnPoint корректно восстанавливается
