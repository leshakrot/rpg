# Новая система динамических компонентов

## 🎉 Что изменилось?

**СТАРАЯ СИСТЕМА:**
- ❌ Нужно было вводить имя типа компонента вручную
- ❌ Нужно было создавать отдельный GameObject с компонентом
- ❌ Копирование полей работало не всегда корректно
- ❌ Нельзя было редактировать поля в Inspector

**НОВАЯ СИСТЕМА:**
- ✅ Перетаскиваете компонент как шаблон
- ✅ Все поля компонента редактируются прямо в SpawnPoint
- ✅ Полное копирование через JsonUtility (100% точность)
- ✅ Автоматическая настройка UnityEvent (Health.onDie)

---

## 📝 Пошаговая инструкция

### Шаг 1: Создайте временный GameObject с компонентом

```
Hierarchy → Right Click → Create Empty
Переименуйте в "Component Templates"

Add Component → QuestProgress
Настройте поля:
  - Quest List: [Ваш квест]
  - Amount: 1
  - etc.
```

> **Примечание:** Этот GameObject нужен только как источник компонента. Можно сделать его невидимым или удалить после настройки SpawnPoint.

---

### Шаг 2: Откройте SpawnPoint в Inspector

Выберите ваш SpawnPoint (например, `/Enemy Spawner/Grunt Spawn Point`)

Найдите раздел:
```
┌─────────────────────────────────────────────────┐
│ Условный спавн и динамические компоненты        │
│   Условия спавна                                │
│   Динамические компоненты                       │
│     Size: 0                                     │
│     [  +  ]  [  -  ]                            │
└─────────────────────────────────────────────────┘
```

---

### Шаг 3: Добавьте компонент в список

Нажмите `+` рядом с "Size"

Появится новый элемент:
```
┌─────────────────────────────────────────────────┐
│ ▼ Element 0                                     │
│     Component Template        None (MonoBehav..)│
│     ▼ Event Binding                             │
│         Event Type            None              │
│         Method Name                             │
└─────────────────────────────────────────────────┘
```

---

### Шаг 4: Перетащите компонент в Component Template

**ВАЖНО:** Перетаскивайте КОМПОНЕНТ, а не GameObject!

Из Hierarchy:
1. Разверните "Component Templates" GameObject
2. Найдите компонент "Quest Progress" в Inspector
3. Перетащите **название компонента "Quest Progress"** (не GameObject!) в поле "Component Template"

Из Project:
1. Выберите префаб с компонентом
2. В Inspector найдите нужный компонент
3. Перетащите его в "Component Template"

---

### Шаг 5: Настройте поля компонента

После перетаскивания появятся все поля:

```
┌──────────────────────────────────────────────────┐
│ ▼ Element 0                                      │
│     Component Template     Quest Progress (Que..│
│                                                  │
│     Template Component Settings:                │
│       Quest List           [My Quest]            │
│       Amount               1                     │
│       (все остальные поля компонента)            │
│                                                  │
│     ▼ Event Binding                              │
│         Event Type         OnDie                 │
│         Method Name        AddProgress           │
└──────────────────────────────────────────────────┘
```

**Редактируйте поля прямо здесь!** Все изменения сохраняются.

---

### Шаг 6: Настройте событие (если нужно)

Если хотите вызвать метод при смерти врага:

```
Event Binding:
  Event Type:    OnDie
  Method Name:   AddProgress
```

Это автоматически добавит вызов в `Health.onDie` UnityEvent!

## 💡 Как это работает?

### При спавне врага:

1. **Создается новый враг** из префаба
2. **Добавляется компонент** (например, QuestProgress)
3. **Копируются все поля** из шаблона через JsonUtility
4. **Настраивается UnityEvent** - в Health.onDie добавляется вызов метода
5. **Готово!** Враг полностью настроен

### Пример готового врага:

```
Enemy Spider (Clone)
  ├─ Transform
  ├─ Health
  │   └─ onDie (UnityEvent)
  │       └─ QuestProgress.AddProgress()  ← автоматически!
  ├─ Quest Progress                       ← добавлен динамически!
  │   ├─ Quest List: [Kill Spiders Quest] ← скопировано из шаблона!
  │   └─ Amount: 1                        ← скопировано из шаблона!
  └─ ... (другие компоненты)
```

## 🔧 Устранение проблем

### Не вижу "Template Component Settings"
→ Убедитесь что перетащили КОМПОНЕНТ, а не GameObject
→ Разверните элемент в списке (нажмите ▼)

### Поля не копируются
→ Убедитесь что поля сериализуемые (public или [SerializeField])
→ Проверьте что компонент настроен в шаблоне

### Метод не вызывается
→ Метод должен быть public
→ Метод без параметров
→ Проверьте точное совпадение имени

### Компонент не добавляется
→ Проверьте Component Template (не должен быть null)
→ Смотрите Console с включенным showDebugInfo

## 📚 Техническая документация

### Как работает копирование полей

```csharp
private void CopyComponentValues(Component source, Component destination)
{
    // Сериализуем источник в JSON
    string json = JsonUtility.ToJson(source);
    
    // Десериализуем в целевой компонент
    JsonUtility.FromJsonOverwrite(json, destination);
}
```

**Что копируется:**
- ✅ Public поля
- ✅ [SerializeField] поля
- ✅ Вложенные структуры
- ✅ Списки и массивы
- ✅ Ссылки на ресурсы

**Что НЕ копируется:**
- ❌ Методы (только данные)
- ❌ События (кроме явно настроенных)
- ❌ Private поля без [SerializeField]

---

### Как работает привязка событий

```csharp
private void BindComponentToEvent(GameObject enemy, Component component, ComponentEventBinding binding)
{
    if (binding.eventType == ComponentEventBinding.EventType.OnDie)
    {
        var health = enemy.GetComponent<Health>();
        var method = component.GetType().GetMethod(binding.methodName);
        
        UnityAction action = () => method.Invoke(component, null);
        health.onDie.AddListener(action);
    }
}
```

**Runtime добавление в UnityEvent** - быстро и безопасно!
