# 🎯 Шпаргалка: Динамический спавн врагов

## 📋 Быстрый старт (3 шага)

### 1️⃣ Создать помощника
```
Hierarchy → Create Empty → "SpawnHelpers"
Add Component → DynamicSpawnHelper
```

### 2️⃣ Настроить точку спавна
```
Выбрать SpawnPoint → Inspector
✓ Use Dynamic Spawn
```

### 3️⃣ Настроить условие или компонент
```
Spawn Condition → + → SpawnHelpers → CheckQuestActive
Components To Add → + → "QuestProgress"
```

---

## 🔧 Основные методы DynamicSpawnHelper

| Метод | Что делает |
|-------|------------|
| `CheckQuestActive` | Проверяет активен ли квест |
| `CheckQuestNotStarted` | Квест еще не взят |
| `CheckQuestCondition` | Цель квеста не выполнена |
| `InvertCondition` | Инвертирует результат |
| `AlwaysSpawn` | Всегда спавнить |
| `NeverSpawn` | Никогда не спавнить |
| `SetupQuestProgress` | Настроить QuestProgress |
| `ConnectQuestProgressToHealth` | Подключить к onDie |

## 📝 Частые сценарии

### Квестовый враг с прогрессом
```
SpawnPoint:
  ✓ Use Dynamic Spawn
  
Spawn Condition:
  + CheckQuestActive(QuestList, Quest)

Components To Add:
  + QuestProgress
    On Component Added:
      + SetupQuestProgress(list, quest, "objective", 1)
      + ConnectQuestProgressToHealth()
```

### Босс после выполнения цели
```
SpawnPoint:
  ✓ Use Dynamic Spawn
  
Spawn Condition:
  + CheckQuestCondition(QuestList, Quest, "objective", 0)
  + InvertCondition()
```

### Зона только для хай-левел
```
SpawnZone:
  ✓ Use Conditional Spawn
  
Zone Spawn Condition:
  + CheckQuestCondition(QuestList, Quest, "", 0)
```

### Враг исчезает при активном квесте
```
SpawnPoint:
  ✓ Use Dynamic Spawn
  
Spawn Condition:
  + CheckQuestActive(QuestList, Quest)
  + InvertCondition()
```

## ⚡ Важные моменты

### ✅ ДА:
- Имя компонента: `QuestProgress` (с большой буквы)
- SpawnHelpers должен быть на сцене
- Параметры в UnityEvent должны быть заполнены

### ❌ НЕТ:
- Не используйте `questProgress` (с маленькой)
- Не забывайте включать `Use Dynamic Spawn`
- Не оставляйте пустыми обязательные параметры

---

## 📖 Структура параметров

### CheckQuestActive
```
параметр 1: QuestList (объект со сцены)
параметр 2: Quest (ScriptableObject)
```

### CheckQuestCondition
```
параметр 1: QuestList
параметр 2: Quest
параметр 3: objectiveReference (строка, например "kill_enemies")
параметр 4: amount (число, обычно 0)
```

### SetupQuestProgress
```
параметр 1: component (Component - автоматически)
параметр 2: questList (QuestList)
параметр 3: questReference (Quest)
параметр 4: objectiveReference (строка)
параметр 5: amount (число, обычно 1)
```

## 🎮 Комбинирование условий

### И (AND):
```
Spawn Condition:
  + Условие1
  + Условие2
  (оба должны быть true)
```

### ИЛИ (OR):
Используйте два SpawnPoint с разными условиями

### НЕ (NOT):
```
Spawn Condition:
  + ЛюбоеУсловие
  + InvertCondition()
```
