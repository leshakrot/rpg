ИСТОРИЯ ИЗМЕНЕНИЙ - СИСТЕМА УСЛОВНОГО СПАВНА
============================================

Версия 1.0 - Реализация условного спавна
----------------------------------------

ДОБАВЛЕНО В EnemySpawner.cs:
---------------------------
+ Список conditionalEnemies для отслеживания временных врагов
+ Метод CheckSpawnConditions() - проверка условий через предикаты
+ Метод AddDynamicComponents() - добавление компонентов на врагов
+ Метод BindComponentToEvent() - привязка методов к событиям
+ Метод SpawnDynamicEnemy() - программный спавн простого врага
+ Метод SpawnDynamicEnemyWithComponents() - спавн врага с компонентами
+ Метод OnDynamicEnemyDied() - обработка смерти динамического врага
+ Using для GameDevTV.Utils, System.Linq, UnityEngine.Events

ИЗМЕНЕНО В EnemySpawner.cs:
--------------------------
* SpawnEnemyAtPoint() - добавлена проверка условий спавна
* SpawnEnemyAtPoint() - добавлен вызов AddDynamicComponents()
* SpawnEnemyAtPoint() - маркировка условных врагов
* OnEnemyDied() - добавлено удаление из conditionalEnemies
* ClearEnemies() - добавлена очистка conditionalEnemies

ДОБАВЛЕНО В SpawnPoint.cs:
-------------------------
+ Поле spawnConditions (Condition) - условия для спавна
+ Список componentsToAdd - компоненты для добавления
+ Метод CheckSpawnConditions() - проверка условий
+ Метод GetComponentsToAdd() - получение списка компонентов
+ Класс ComponentToAdd - описание компонента для добавления
+ Класс ComponentEventBinding - привязка к событиям
+ Using для GameDevTV.Utils, UnityEngine.Events, System

НОВЫЕ ФАЙЛЫ:
-----------
+ DynamicEnemySpawnExample.cs - примеры использования API
+ RandomEncounterTrigger.cs - компонент случайных встреч
+ README_ConditionalSpawning.txt - полная документация
+ CHANGELOG_ConditionalSpawning.txt - история изменений

ОПТИМИЗАЦИЯ:
-----------
* Автоматическое удаление условных врагов из памяти
* Корректная очистка при смене сцен
* Отслеживание временных врагов отдельно

СОВМЕСТИМОСТЬ:
-------------
✓ Полная совместимость с существующей системой спавна
✓ Работа с системой сохранений (ISaveable)
✓ Интеграция с системой квестов
✓ Интеграция с системой предикатов

BREAKING CHANGES:
----------------
Нет. Все изменения обратно совместимы.

МИГРАЦИЯ:
--------
Не требуется. Существующие SpawnPoint и EnemySpawner 
работают как раньше без изменений.

ИСПОЛЬЗОВАНИЕ НОВЫХ ВОЗМОЖНОСТЕЙ:
--------------------------------
1. Для условного спавна: добавьте Condition в SpawnPoint
2. Для динамических компонентов: заполните componentsToAdd
3. Для программного спавна: используйте SpawnDynamicEnemy()

ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ:
---------------------
- Поддерживается только событие OnDie
- Компоненты должны наследоваться от MonoBehaviour
- Методы для привязки должны быть public без параметров

ПЛАНЫ НА БУДУЩЕЕ:
----------------
- Поддержка дополнительных событий (OnTakeDamage, OnSpawn)
- Редактор для визуальной настройки компонентов
- Пулинг для оптимизации производительности
- Поддержка async/await для спавна
