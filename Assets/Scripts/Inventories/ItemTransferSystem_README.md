# Система передачи предметов квестовым персонажам

## Обзор
Система позволяет передавать предметы из инвентаря игрока квестовым персонажам через диалоги с использованием DialogueTrigger.

## Компоненты системы

### 1. ItemTransferSystem.cs
Основной класс для обработки передачи предметов. Обеспечивает безопасное удаление предметов из инвентаря с проверками количества.

**Основные методы:**
- `TransferItemFromPlayer(InventoryItem item, int quantity)` - передает предмет по ссылке
- `TransferItemFromPlayerByID(string itemID, int quantity)` - передает предмет по ID
- `HasEnoughItems(InventoryItem item, int quantity)` - проверяет наличие достаточного количества предметов

### 2. QuestItemTransfer.cs
Расширенный компонент для настройки передачи нескольких предметов с удобным интерфейсом в Inspector.

**Возможности:**
- Настройка нескольких предметов для передачи
- Поддержка как ScriptableObject ссылок, так и ID предметов
- Передача отдельных предметов или всех сразу
- Настраиваемые сообщения об успехе/неудаче

### 3. SimpleItemTransfer.cs
Упрощенный компонент для передачи одного предмета. Идеален для простых диалогов.

**Возможности:**
- Настройка одного предмета
- Простой интерфейс
- Поддержка как ScriptableObject, так и ID

### 4. ItemChecker.cs
Компонент для проверки наличия предметов. Реализует IPredicateEvaluator для использования в диалогах.

**Предикаты:**
- `HasRequiredItems` - проверяет все настроенные предметы
- `HasItemForTransfer` - проверяет конкретный предмет по ID
- `CanTransferAllItems` - алиас для HasRequiredItems

## Инструкция по использованию

### Шаг 1: Настройка NPC
1. Добавьте к NPC компонент `DialogueTrigger` (если еще не добавлен)
2. Добавьте один из компонентов передачи предметов:
   - `SimpleItemTransfer` - для простых случаев (один предмет)
   - `QuestItemTransfer` - для сложных случаев (несколько предметов)

### Шаг 2: Настройка предметов
В компоненте передачи предметов:
- **Вариант 1 (рекомендуется):** Перетащите ScriptableObject предмета в поле "Item To Transfer"
- **Вариант 2:** Введите ID предмета в поле "Item ID"
- Укажите количество для передачи

### Шаг 3: Настройка DialogueTrigger
1. В списке Actions добавьте новое действие
2. Укажите уникальное имя действия (например, "TransferBranches")
3. В UnityEvent выберите ваш объект NPC
4. Выберите функцию из компонента передачи предметов:
   - `SimpleItemTransfer.TransferItem()` - для простой передачи
   - `QuestItemTransfer.TransferSingleItem(int)` - для передачи конкретного предмета
   - `QuestItemTransfer.TransferAllRequiredItems()` - для передачи всех предметов

### Шаг 4: Использование в диалоге
В редакторе диалогов укажите имя действия в поле Action диалогового узла.

## Примеры использования

### Пример 1: Простая передача веток
```
NPC говорит: "Мне нужно 5 веток для постройки забора"
Игрок выбирает: "Вот ваши ветки" [Action: "TransferBranches"]
```

Настройки SimpleItemTransfer:
- Item To Transfer: BranchItem (ScriptableObject)
- Quantity: 5

### Пример 2: Передача нескольких предметов
```
NPC говорит: "Для зелья мне нужны травы и грибы"
Игрок выбирает: "У меня есть все ингредиенты" [Action: "TransferIngredients"]
```

Настройки QuestItemTransfer:
- Required Items[0]: HerbItem, quantity: 3
- Required Items[1]: MushroomItem, quantity: 2

### Пример 3: Условная передача
Для проверки наличия предметов перед показом опции диалога:
1. Добавьте ItemChecker к NPC
2. В диалоге используйте предикат: `HasItemForTransfer BranchID 5`

## Безопасность системы

Система автоматически:
- Проверяет наличие достаточного количества предметов
- Корректно обрабатывает стакируемые предметы
- Удаляет предметы из нескольких слотов при необходимости
- Сохраняет остатки предметов (например, если есть 6 веток, а нужно 5, остается 1)
- Выводит предупреждения при недостатке предметов

## Отладка

Все компоненты имеют:
- Контекстные меню для тестирования в play mode
- Подробное логирование операций
- Проверки валидности данных

Для отладки используйте:
- `Check Item Availability` в контекстном меню компонента
- Console логи с подробной информацией о передачах
- `Test Transfer` для быстрого тестирования
