# DropLibrary - Система выпадения предметов

## Обзор
`DropLibrary` - это система, позволяющая настраивать выпадение предметов из различных источников (враги, сундуки, и т.д.) с гибкими настройками шансов и количества в зависимости от уровня игрока или других факторов.

## Особенности
- **Диапазоны уровней** - вместо настройки каждого уровня отдельно, система использует диапазоны уровней для более удобной настройки
- **Глобальные настройки** - единые настройки шанса дропа и количества предметов
- **Индивидуальные настройки для предметов** - каждый предмет может иметь свои настройки шанса и количества
- **Поддержка стакуемых предметов** - гибкое управление минимальным и максимальным количеством для стакуемых предметов
- **Удобный редактор** - специальный пользовательский интерфейс для удобной настройки в инспекторе Unity

## Как создать новую библиотеку дропа
1. В окне проекта щелкните правой кнопкой мыши и выберите **Create > RPG > Inventory > DropLibrary**
2. Задайте имя для новой библиотеки (например, "EnemyDrops", "ChestDrops" и т.д.)
3. Настройте библиотеку в инспекторе

## Настройка DropLibrary

### Глобальные настройки
- **Шанс дропа (%)** - вероятность того, что что-либо выпадет (от 0 до 100)
- **Мин. предметов** - минимальное количество различных предметов, которые могут выпасть за один раз
- **Макс. предметов** - максимальное количество различных предметов, которые могут выпасть за один раз
- **Настройки по уровням** - включает режим, где шанс дропа зависит от уровня

### Предметы для выпадения
Список всех предметов, которые могут выпасть из данного источника.

Для каждого предмета можно настроить:
- **Предмет** - ссылка на InventoryItem, который может выпасть
- **Шанс выпадения** - относительный шанс выпадения данного предмета (чем больше значение, тем выше шанс)
- **Мин. количество** - минимальное количество предмета при выпадении (для стакуемых предметов)
- **Макс. количество** - максимальное количество предмета при выпадении (для стакуемых предметов)

### Настройка по диапазонам уровней
Вместо указания значений для каждого уровня отдельно, система использует диапазоны уровней:

1. Активируйте опцию "Настройки по уровням" или соответствующую опцию для конкретного параметра
2. Нажмите "Добавить диапазон"
3. Укажите:
   - **От уровня** - начальный уровень диапазона
   - **До уровня** - конечный уровень диапазона
   - **Значение** - значение параметра для этого диапазона уровней

Например:
- Диапазон #1: От уровня 1, До уровня 5, Шанс дропа: 30%
- Диапазон #2: От уровня 6, До уровня 10, Шанс дропа: 40%
- Диапазон #3: От уровня 11, До уровня 20, Шанс дропа: 50%

## Интеграция с другими системами

### Использование с RandomDropper
Компонент `RandomDropper` автоматически работает с `DropLibrary`. Чтобы настроить:

1. Добавьте компонент `RandomDropper` к объекту
2. Перетащите созданную библиотеку дропа в поле "Drop Library"
3. При вызове `RandomDrop()` система автоматически определит уровень через компонент `BaseStats` и сгенерирует дроп соответственно

### Программное использование
```csharp
// Получение библиотеки дропа
DropLibrary dropLibrary = ...;

// Получение предметов для заданного уровня
int level = 5;
foreach (var drop in dropLibrary.GetRandomDrops(level))
{
    // drop.item - выпавший предмет
    // drop.number - количество
    Debug.Log($"Выпал предмет: {drop.item.name}, количество: {drop.number}");
    
    // Применение дропа (например, через ItemDropper)
    itemDropper.DropItem(drop.item, drop.number);
}
```

## Советы по настройке
1. **Настройка для большого количества уровней**:
   - Разбивайте уровни на логические диапазоны (например, 1-5, 6-10, 11-20, и т.д.)
   - Используйте меньшее количество диапазонов с более широким охватом для высоких уровней

2. **Балансировка шансов выпадения**:
   - Сумма всех шансов выпадения не должна быть равна 100% - система использует относительные шансы
   - Если вы хотите, чтобы предмет выпадал в 2 раза чаще другого, его шанс должен быть в 2 раза выше

3. **Проверка настроек**:
   - Система автоматически проверяет корректность диапазонов уровней и других параметров
   - Если максимальное количество меньше минимального, система автоматически исправит это

## Расширенное использование
- Для очень редких предметов используйте значения шанса меньше 1 (например, 0.1)
- Чтобы предмет выпадал только на определенных уровнях, создайте для него отдельный диапазон
- Для экипируемых предметов количество всегда будет равно 1, независимо от настроек минимального и максимального количества
