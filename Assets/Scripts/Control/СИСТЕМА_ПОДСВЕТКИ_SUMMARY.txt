БЫСТРЫЙ СТАРТ (3 ШАГА):
-----------------------

1. Tools > Setup > Add Highlight to All Interactables
   └─> Добавляет компонент ко всем интерактивным объектам в сцене

2. Tools > Highlight Colors > Apply All Presets
   └─> Применяет цветовые схемы по типам объектов

3. Запустите игру и наведите курсор на объекты
   └─> Объекты будут подсвечиваться!

ТЕХНИЧЕСКИЕ ХАРАКТЕРИСТИКИ:
---------------------------

Производительность:
  • 1 SphereCast в Update() HighlightManager
  • Кэширование материалов при инициализации
  • Изменение материалов только при смене объекта
  • Минимальное влияние на FPS

Совместимость:
  • Unity 2019.4+
  • Built-in Render Pipeline
  • Universal Render Pipeline (URP)
  • High Definition Render Pipeline (HDRP)

Требования к материалам:
  • Shader с поддержкой Emission
  • Наличие свойства _EmissionColor
  • Рекомендуется: Standard, URP/Lit, HDRP/Lit

Автоматизация:
  • Автоматическое добавление при создании IRaycastable
  • Автоматическая регистрация в HighlightManager
  • Автоматическая очистка при удалении объекта

РЕШЕНИЕ ПРОБЛЕМ:
----------------

Проблема: Подсветка не работает
Решение:
  1. Tools > Validate > Check Highlight System
  2. Проверьте Console на ошибки
  3. Убедитесь, что материал поддерживает Emission
  4. Проверьте наличие Renderer на объекте

Проблема: Подсветка слишком яркая/тусклая
Решение:
  1. Выберите объект
  2. Измените Highlight Intensity в Inspector
  3. Рекомендуемый диапазон: 0.5 - 3.0

Проблема: Подсвечиваются дочерние объекты, которые не нужны
Решение:
  1. Выберите InteractableHighlight
  2. Снимите галочку Include Children
  3. Убедитесь, что у основного объекта есть Renderer

Проблема: Объект не подсвечивается при наведении
Решение:
  1. Проверьте, что объект имеет IRaycastable
  2. Проверьте, что InteractableHighlight включен
  3. Проверьте, что объект не заблокирован другим объектом
  4. Проверьте, что курсор не над UI

РАСШИРЕНИЕ СИСТЕМЫ:
-------------------

Добавление нового типа интерактивного объекта:
  1. Создайте класс, наследующий InteractableObject или IRaycastable
  2. InteractableHighlight добавится автоматически
  3. Настройте цвет в Inspector или через пресеты

Создание собственного пресета:
  1. Откройте HighlightColorPresets.cs
  2. Добавьте новый цвет: private static readonly Color MyColor = new Color(r, g, b);
  3. Создайте метод с атрибутом [MenuItem("Tools/Highlight Colors/My Preset")]
  4. Используйте SetHighlightColor() для применения

Изменение логики подсветки:
  1. Откройте HighlightManager.cs
  2. Измените метод UpdateHighlight() или GetHighlightUnderCursor()
  3. Сохраните и протестируйте
