  СИСТЕМА ПОДСВЕТКИ ИНТЕРАКТИВНЫХ ОБЪЕКТОВ

БЫСТРЫЙ СТАРТ:
--------------
1. Откройте Unity Editor
2. Меню: Tools > Setup > Add Highlight to All Interactables
3. Готово! Все интерактивные объекты теперь подсвечиваются при наведении курсора

НАСТРОЙКА ПАРАМЕТРОВ:
---------------------
Выберите объект с InteractableHighlight и настройте в Inspector:

• Highlight Color - цвет подсветки (по умолчанию: желто-оранжевый)
• Highlight Intensity - яркость свечения (по умолчанию: 1.5)
• Include Children - подсвечивать дочерние объекты (по умолчанию: включено)

ПРОВЕРКА СИСТЕМЫ:
-----------------
Меню: Tools > Validate > Check Highlight System
Покажет статистику и предупреждения о проблемах

ВАЖНО:
------
• Материалы должны поддерживать Emission (Standard, URP/Lit и т.д.)
• Система автоматически добавляется к новым интерактивным объектам
• Не подсвечивает объекты, когда курсор над UI
• Минимальное влияние на производительность

УДАЛЕНИЕ:
---------
Меню: Tools > Setup > Remove Highlight from All Interactables
