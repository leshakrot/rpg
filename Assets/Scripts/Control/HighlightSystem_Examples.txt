ПРИМЕР 1: БАЗОВАЯ НАСТРОЙКА
----------------------------
1. Создайте новый GameObject с InteractableObject (например, Shop)
2. InteractableHighlight автоматически добавится при добавлении компонента
3. Настройте цвет подсветки в Inspector
4. Запустите игру - объект будет подсвечиваться при наведении

ПРИМЕР 2: НАСТРОЙКА ЦВЕТА ДЛЯ РАЗНЫХ ТИПОВ ОБЪЕКТОВ
----------------------------------------------------
Рекомендуемые цвета для разных типов:

• Ресурсы (деревья, руда, травы):
  Color: (0.4, 1.0, 0.4) - зеленый
  Intensity: 1.5

• NPC и диалоги (AIConversant):
  Color: (0.4, 0.8, 1.0) - голубой
  Intensity: 1.2

• Магазины и станции крафта:
  Color: (1.0, 0.8, 0.2) - золотой
  Intensity: 1.8

• Сундуки и контейнеры:
  Color: (1.0, 0.6, 0.2) - оранжевый
  Intensity: 1.5

• Враги (CombatTarget):
  Color: (1.0, 0.2, 0.2) - красный
  Intensity: 2.0

ПРИМЕР 3: МАССОВОЕ ИЗМЕНЕНИЕ ЦВЕТА
-----------------------------------
Используйте этот C# скрипт в Editor для массового изменения:

using UnityEngine;
using UnityEditor;
using RPG.Control;
using RPG.Harvesting;

public class SetHighlightColors
{
    [MenuItem("Tools/Setup/Set Resource Highlight Colors")]
    static void SetResourceColors()
    {
        HarvestableSource[] resources = Object.FindObjectsOfType<HarvestableSource>();
        foreach (var resource in resources)
        {
            InteractableHighlight highlight = resource.GetComponent<InteractableHighlight>();
            if (highlight != null)
            {
                SerializedObject so = new SerializedObject(highlight);
                so.FindProperty("highlightColor").colorValue = new Color(0.4f, 1f, 0.4f);
                so.FindProperty("highlightIntensity").floatValue = 1.5f;
                so.ApplyModifiedProperties();
            }
        }
        Debug.Log($"Updated {resources.Length} resources");
    }
}

ПРИМЕР 4: ОТКЛЮЧЕНИЕ ПОДСВЕТКИ ДЛЯ КОНКРЕТНОГО ОБЪЕКТА
-------------------------------------------------------
Если нужно отключить подсветку для конкретного объекта:
1. Выберите объект
2. Удалите компонент InteractableHighlight
3. Объект останется интерактивным, но не будет подсвечиваться

ПРИМЕР 5: ПОДСВЕТКА ТОЛЬКО ОСНОВНОГО ОБЪЕКТА (БЕЗ ДЕТЕЙ)
----------------------------------------------------------
Если объект имеет много дочерних объектов и вы хотите подсветить только основной:
1. Выберите InteractableHighlight на объекте
2. Снимите галочку "Include Children"
3. Убедитесь, что у основного объекта есть Renderer

ПРИМЕР 6: НАСТРОЙКА МАТЕРИАЛОВ ДЛЯ ПОДСВЕТКИ
---------------------------------------------
Если материал не поддерживает Emission:

1. Выберите материал в Project
2. Измените Shader на:
   - Standard (для Built-in RP)
   - Universal Render Pipeline/Lit (для URP)
3. В Inspector материала найдите секцию "Emission"
4. Включите Emission (если нужно базовое свечение)

ПРИМЕР 7: ПРОВЕРКА РАБОТЫ СИСТЕМЫ
----------------------------------
1. Меню: Tools > Validate > Check Highlight System
2. Проверьте Console на предупреждения
3. Исправьте объекты без Renderer или без поддержки Emission
4. Повторите проверку

ПРИМЕР 8: ОТЛАДКА ПРОБЛЕМ
--------------------------
Если подсветка не работает:

1. Проверьте, что объект имеет IRaycastable
2. Проверьте, что InteractableHighlight добавлен
3. Проверьте, что у объекта есть Renderer
4. Проверьте, что материал поддерживает _EmissionColor
5. Проверьте, что HighlightManager существует в сцене (создается автоматически)
6. Проверьте Console на ошибки

ПРИМЕР 9: ПРОИЗВОДИТЕЛЬНОСТЬ
-----------------------------
Система оптимизирована, но для больших сцен:

• Используйте Include Children = false где возможно
• Убедитесь, что у объектов минимальное количество материалов
• Система кэширует материалы при старте, не при каждом кадре

ПРИМЕР 10: ИНТЕГРАЦИЯ С НОВЫМИ ТИПАМИ ОБЪЕКТОВ
-----------------------------------------------
Если вы создаете новый тип интерактивного объекта:

1. Наследуйтесь от InteractableObject или реализуйте IRaycastable
2. InteractableHighlight добавится автоматически
3. Настройте цвет и интенсивность в Inspector
4. Готово!
