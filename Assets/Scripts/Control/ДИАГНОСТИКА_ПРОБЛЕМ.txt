═══════════════════════════════════════════════════════════════════════════════

ПРОБЛЕМА 1: ПОДСВЕТКА НЕ РАБОТАЕТ НА НЕКОТОРЫХ ОБЪЕКТАХ
---------------------------------------------------------

Шаг 1: Проверьте систему
  → Tools > Validate > Check Highlight System
  → Посмотрите Console на предупреждения

Шаг 2: Выберите проблемный объект и проанализируйте материалы
  → Tools > Debug > Analyze Selected Object Materials
  → Проверьте, поддерживают ли материалы _EmissionColor

Шаг 3: Если материалы не поддерживают Emission
  → Tools > Debug > Fix Material Emission Settings
  ИЛИ
  → Измените Shader материала на:
    • Standard (Built-in RP)
    • Universal Render Pipeline/Lit (URP)
    • HDRP/Lit (HDRP)

═══════════════════════════════════════════════════════════════════════════════

ПРОБЛЕМА 2: ПОДСВЕТКА БЕЛОГО ЦВЕТА ВМЕСТО НАСТРОЕННОГО
-------------------------------------------------------

Причина: Материал использует HDR или неправильные настройки Emission

Решение 1: Проверьте настройки InteractableHighlight
  1. Выберите объект
  2. В Inspector найдите InteractableHighlight
  3. Проверьте Highlight Color (должен быть цветной, не белый)
  4. Проверьте Highlight Intensity (рекомендуется 1.0-2.0)

Решение 2: Проверьте материал
  1. Выберите объект
  2. Tools > Debug > Analyze Selected Object Materials
  3. Проверьте текущий цвет Emission в материале
  4. Если он белый, используйте:
     Tools > Debug > Fix Material Emission Settings

Решение 3: Примените цветовые пресеты
  → Tools > Highlight Colors > Apply All Presets
  ИЛИ выберите конкретный пресет для типа объекта

═══════════════════════════════════════════════════════════════════════════════

ПРОБЛЕМА 3: ПОДСВЕТКА РАБОТАЕТ, НО ОЧЕНЬ СЛАБАЯ
------------------------------------------------

Решение:
  1. Выберите объект с InteractableHighlight
  2. Увеличьте Highlight Intensity до 2.0-3.0
  3. Или измените Highlight Color на более яркий

Для массового изменения:
  1. Откройте HighlightColorPresets.cs
  2. Измените значения intensity в методах Apply...Colors()
  3. Запустите нужный пресет

═══════════════════════════════════════════════════════════════════════════════

ПРОБЛЕМА 4: ПОДСВЕТКА СЛИШКОМ ЯРКАЯ
------------------------------------

Решение:
  1. Выберите объект с InteractableHighlight
  2. Уменьшите Highlight Intensity до 0.5-1.0
  3. Или выберите менее яркий цвет

═══════════════════════════════════════════════════════════════════════════════

ПРОБЛЕМА 5: ПОДСВЕТКА НЕ ОТКЛЮЧАЕТСЯ
-------------------------------------

Причина: Возможная ошибка в коде или материалы не восстанавливаются

Решение:
  1. Остановите Play Mode
  2. Перезапустите Unity Editor
  3. Проверьте Console на ошибки
  4. Если проблема повторяется, удалите и заново добавьте InteractableHighlight

═══════════════════════════════════════════════════════════════════════════════

ПРОБЛЕМА 6: ПОДСВЕТКА РАБОТАЕТ ТОЛЬКО НА ЧАСТИ ОБЪЕКТА
-------------------------------------------------------

Причина: Не все материалы поддерживают Emission

Решение:
  1. Выберите объект
  2. Tools > Debug > Analyze Selected Object Materials
  3. Найдите материалы без поддержки _EmissionColor
  4. Измените их Shader на Standard/URP Lit/HDRP Lit
  ИЛИ
  5. Tools > Debug > Fix Material Emission Settings

═══════════════════════════════════════════════════════════════════════════════

ПРОБЛЕМА 7: ПОДСВЕТКА НЕ РАБОТАЕТ В PLAY MODE
----------------------------------------------

Шаг 1: Проверьте, что HighlightManager создан
  → В Hierarchy должен быть объект "HighlightManager"
  → Если нет, он создастся автоматически при первом обращении

Шаг 2: Проверьте Console на ошибки
  → Возможны ошибки компиляции или runtime ошибки

Шаг 3: Проверьте, что InteractableHighlight включен
  → Выберите объект в Play Mode
  → Проверьте, что компонент InteractableHighlight активен (галочка)

Шаг 4: Проверьте, что курсор не над UI
  → Система не подсвечивает объекты, когда курсор над UI элементами

═══════════════════════════════════════════════════════════════════════════════

ПРОБЛЕМА 8: ПОДСВЕТКА МЕРЦАЕТ
------------------------------

Причина: Несколько объектов накладываются друг на друга

Решение:
  1. Проверьте, что объекты не пересекаются
  2. Используйте Layers для разделения объектов
  3. Настройте Raycast Radius в HighlightManager (меньше значение)

═══════════════════════════════════════════════════════════════════════════════

ПРОБЛЕМА 9: НИЗКАЯ ПРОИЗВОДИТЕЛЬНОСТЬ
--------------------------------------

Решение 1: Отключите Include Children для сложных объектов
  1. Выберите объект с InteractableHighlight
  2. Снимите галочку Include Children
  3. Убедитесь, что у основного объекта есть Renderer

Решение 2: Уменьшите количество материалов
  → Объедините материалы где возможно

Решение 3: Используйте LOD (Level of Detail)
  → Подсветка будет работать только на видимых LOD

ТЕСТИРОВАНИЕ ПОДСВЕТКИ
----------------------

Тест 1: Проверка конкретного объекта
  1. Выберите объект в Hierarchy
  2. Tools > Debug > Test Highlight on Selected
  3. Подсветка включится на 2 секунды

Тест 2: Анализ материалов
  1. Выберите объект
  2. Tools > Debug > Analyze Selected Object Materials
  3. Проверьте Console на детальный отчет

Тест 3: Валидация всей системы
  → Tools > Validate > Check Highlight System

ЧАСТЫЕ ОШИБКИ
-------------

❌ Материал использует Unlit shader
   → Измените на Standard/Lit shader

❌ У объекта нет Renderer
   → Добавьте MeshRenderer или другой Renderer

❌ InteractableHighlight отключен (disabled)
   → Включите компонент в Inspector

❌ Объект находится на слое, который не рейкастится
   → Проверьте Layer Settings

❌ Collider отсутствует или отключен
   → Добавьте Collider для raycast

КОНТРОЛЬНЫЙ СПИСОК ДИАГНОСТИКИ
-------------------------------

□ Tools > Validate > Check Highlight System
□ Проверить Console на ошибки и предупреждения
□ Выбрать проблемный объект
□ Tools > Debug > Analyze Selected Object Materials
□ Проверить Shader материалов (должен поддерживать Emission)
□ Проверить настройки InteractableHighlight (цвет, intensity)
□ Проверить наличие Renderer
□ Проверить наличие Collider
□ Протестировать в Play Mode
□ Проверить, что курсор не над UI

ЕСЛИ НИЧЕГО НЕ ПОМОГЛО
-----------------------

1. Удалите InteractableHighlight с проблемного объекта
2. Сохраните сцену
3. Перезапустите Unity Editor
4. Добавьте InteractableHighlight заново
5. Настройте параметры
6. Протестируйте

Если проблема сохраняется:
→ Проверьте, что используете правильный Render Pipeline
→ Проверьте Project Settings > Graphics
→ Создайте новый тестовый объект с простым материалом
