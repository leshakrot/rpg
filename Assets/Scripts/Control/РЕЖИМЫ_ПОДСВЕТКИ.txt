ТЕПЕРЬ СИСТЕМА ПОДДЕРЖИВАЕТ 3 РЕЖИМА ПОДСВЕТКИ!

Это решает проблему с материалами, которые не поддерживают Emission.

═══════════════════════════════════════════════════════════════════════════════

РЕЖИМ 1: EMISSION (Подсветка через Emission)
---------------------------------------------

Как работает:
  • Включает Emission в материале
  • Устанавливает _EmissionColor
  • Создает эффект свечения

Требования:
  • Материал должен поддерживать _EmissionColor
  • Работает с: Standard, URP/Lit, HDRP/Lit

Плюсы:
  ✓ Красивый эффект свечения
  ✓ Не меняет основной цвет объекта
  ✓ Хорошо видно в темноте

Минусы:
  ✗ Не работает с Unlit и некоторыми custom шейдерами
  ✗ Может быть слишком ярким

Когда использовать:
  → Для объектов со Standard/Lit материалами
  → Когда нужен эффект свечения

═══════════════════════════════════════════════════════════════════════════════

РЕЖИМ 2: COLOR TINT (Подсветка через изменение цвета)
------------------------------------------------------

Как работает:
  • Смешивает оригинальный цвет с цветом подсветки
  • Изменяет _Color, _BaseColor или _MainColor
  • Создает эффект окрашивания

Требования:
  • Материал должен иметь свойство цвета
  • Работает практически со всеми материалами

Плюсы:
  ✓ Работает с любыми материалами (даже Unlit)
  ✓ Универсальное решение
  ✓ Настраиваемая сила эффекта (Color Tint Strength)

Минусы:
  ✗ Меняет основной цвет объекта
  ✗ Может быть менее заметным

Когда использовать:
  → Для Unlit материалов
  → Для custom шейдеров без Emission
  → Когда Emission не работает

Настройка:
  • Color Tint Strength: 0.0-1.0
    - 0.0 = нет эффекта
    - 0.4 = рекомендуется (по умолчанию)
    - 1.0 = полная замена цвета

═══════════════════════════════════════════════════════════════════════════════

РЕЖИМ 3: EMISSION OR COLOR TINT (Гибридный режим) ⭐ РЕКОМЕНДУЕТСЯ
-------------------------------------------------------------------

Как работает:
  • Сначала пробует использовать Emission
  • Если Emission не поддерживается, использует Color Tint
  • Автоматически выбирает лучший метод для каждого материала

Требования:
  • Нет специальных требований
  • Работает с любыми материалами

Плюсы:
  ✓ Универсальное решение
  ✓ Работает на ВСЕХ объектах
  ✓ Автоматический выбор метода
  ✓ Не требует настройки

Минусы:
  ✗ Нет (это лучший выбор!)

Когда использовать:
  → ВСЕГДА (это режим по умолчанию)
  → Для смешанных сцен с разными материалами
  → Когда не хотите разбираться с типами материалов

═══════════════════════════════════════════════════════════════════════════════

КАК ИЗМЕНИТЬ РЕЖИМ:
-------------------

Для одного объекта:
  1. Выберите объект в Hierarchy
  2. Найдите компонент InteractableHighlight в Inspector
  3. Измените параметр "Mode":
     • Emission - только свечение
     • Color Tint - только окрашивание
     • Emission Or Color Tint - автоматический выбор (рекомендуется)

Для всех объектов:
  1. Используйте скрипт массового изменения (см. ниже)

═══════════════════════════════════════════════════════════════════════════════

НАСТРОЙКА ПАРАМЕТРОВ:
---------------------

Highlight Color:
  • Цвет подсветки
  • Рекомендуется яркие цвета: желтый, оранжевый, зеленый

Highlight Intensity:
  • Яркость подсветки (0.1 - 5.0)
  • Для Emission: 1.0 - 2.0
  • Для Color Tint: не влияет

Color Tint Strength:
  • Сила окрашивания (0.0 - 1.0)
  • Только для режимов Color Tint и Emission Or Color Tint
  • Рекомендуется: 0.3 - 0.5

Include Children:
  • Подсвечивать дочерние объекты
  • Включено по умолчанию

═══════════════════════════════════════════════════════════════════════════════

ДИАГНОСТИКА МАТЕРИАЛОВ:
-----------------------

Чтобы узнать, какой режим подходит для вашего объекта:

1. Выберите объект в Hierarchy
2. Меню: Tools > Debug > Analyze Selected Object Materials
3. Посмотрите в Console рекомендацию:
   • "Recommended Mode: Emission" - материал поддерживает Emission
   • "Recommended Mode: ColorTint" - только Color Tint
   • "Recommended Mode: EmissionOrColorTint" - поддерживает оба

═══════════════════════════════════════════════════════════════════════════════

ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ:
----------------------

Пример 1: Стандартные объекты (Standard материал)
  Mode: Emission Or Color Tint (по умолчанию)
  Highlight Intensity: 1.5
  → Будет использовать Emission

Пример 2: Простые объекты (Unlit материал)
  Mode: Emission Or Color Tint (по умолчанию)
  Color Tint Strength: 0.4
  → Будет использовать Color Tint

Пример 3: Смешанная сцена
  Mode: Emission Or Color Tint (для всех объектов)
  → Автоматически выберет лучший метод для каждого

Пример 4: Только свечение (для красоты)
  Mode: Emission
  Highlight Intensity: 2.0
  → Только объекты с поддержкой Emission будут подсвечиваться

Пример 5: Гарантированная подсветка всех объектов
  Mode: Color Tint
  Color Tint Strength: 0.5
  → Все объекты будут подсвечиваться через окрашивание

МАССОВОЕ ИЗМЕНЕНИЕ РЕЖИМА:
---------------------------

Создайте Editor скрипт для массового изменения:

using UnityEngine;
using UnityEditor;
using RPG.Control;

public class SetHighlightMode
{
    [MenuItem("Tools/Highlight/Set All To Emission Or Color Tint")]
    static void SetAllToHybrid()
    {
        InteractableHighlight[] highlights = Object.FindObjectsOfType<InteractableHighlight>();
        foreach (var h in highlights)
        {
            SerializedObject so = new SerializedObject(h);
            so.FindProperty("mode").enumValueIndex = 2; // EmissionOrColorTint
            so.ApplyModifiedProperties();
        }
        Debug.Log($"Updated {highlights.Length} objects");
    }
}

РЕШЕНИЕ ПРОБЛЕМ:
----------------

Проблема: Подсветка не работает на некоторых объектах
Решение: Измените Mode на "Emission Or Color Tint"

Проблема: Подсветка слишком слабая
Решение: 
  • Для Emission: увеличьте Highlight Intensity
  • Для Color Tint: увеличьте Color Tint Strength

Проблема: Подсветка меняет цвет объекта
Решение: Используйте режим Emission (если материал поддерживает)

Проблема: Хочу, чтобы ВСЕ объекты подсвечивались
Решение: Используйте режим "Emission Or Color Tint" (по умолчанию)

✓ Используйте яркие цвета для лучшей видимости
✓ Проверяйте материалы через Tools > Debug > Analyze Selected Object Materials
