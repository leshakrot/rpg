  СИСТЕМА ПОДСВЕТКИ ИНТЕРАКТИВНЫХ ОБЪЕКТОВ
═══════════════════════════════════════════════════════════════════════════════

ОПИСАНИЕ:
---------
Система автоматически подсвечивает интерактивные объекты (Interactable, 
ресурсы, AIConversant и т.д.) при наведении курсора мыши путем изменения 
Emission материала объекта.

КОМПОНЕНТЫ:
-----------
1. InteractableHighlight.cs - компонент для управления подсветкой отдельного объекта
2. HighlightManager.cs - singleton-менеджер для отслеживания курсора
3. InteractableHighlightSetup.cs - Editor-утилита для массового добавления
4. InteractableHighlightAutoSetup.cs - автоматическое добавление при создании

ИСПОЛЬЗОВАНИЕ:
--------------

АВТОМАТИЧЕСКАЯ НАСТРОЙКА (рекомендуется):
1. Откройте Unity Editor
2. В меню выберите: Tools > Setup > Add Highlight to All Interactables
3. Система автоматически добавит компонент InteractableHighlight ко всем 
   объектам с IRaycastable в текущей сцене

РУЧНАЯ НАСТРОЙКА:
1. Выберите GameObject с компонентом IRaycastable (InteractableObject, 
   HarvestableSource, AIConversant и т.д.)
2. Добавьте компонент InteractableHighlight
3. Настройте параметры в Inspector:
   - Highlight Color: цвет подсветки (по умолчанию: желто-оранжевый)
   - Highlight Intensity: интенсивность свечения (по умолчанию: 1.5)
   - Include Children: подсвечивать дочерние объекты (по умолчанию: true)

АВТОМАТИЧЕСКОЕ ДОБАВЛЕНИЕ:
При добавлении нового компонента IRaycastable к объекту, система автоматически 
добавит InteractableHighlight (работает только в Editor).

НАСТРОЙКА МАТЕРИАЛОВ:
---------------------
Для корректной работы подсветки материалы объектов должны:
1. Поддерживать Emission (Standard Shader, URP/Lit и т.д.)
2. Иметь свойство _EmissionColor

Если материал не поддерживает Emission, подсветка не будет работать для этого 
материала, но не вызовет ошибок.

УДАЛЕНИЕ СИСТЕМЫ:
-----------------
Если нужно удалить систему подсветки:
1. В меню выберите: Tools > Setup > Remove Highlight from All Interactables
2. Удалите файлы:
   - InteractableHighlight.cs
   - HighlightManager.cs
   - InteractableHighlightSetup.cs
   - InteractableHighlightAutoSetup.cs
   - InteractableHighlight_README.txt

ТЕХНИЧЕСКИЕ ДЕТАЛИ:
-------------------
- Система использует singleton-паттерн для HighlightManager
- Подсветка работает через изменение _EmissionColor и включение/выключение 
  keyword "_EMISSION"
- Оригинальные значения Emission сохраняются и восстанавливаются при снятии 
  подсветки
- Система автоматически обрабатывает объекты с несколькими материалами
- Поддерживает подсветку дочерних объектов (опционально)
- Использует SphereCast для определения объекта под курсором
- Совместима с существующей системой IRaycastable

ПРОИЗВОДИТЕЛЬНОСТЬ:
-------------------
- Минимальное влияние на производительность
- Один raycast в Update() HighlightManager
- Кэширование материалов при инициализации
- Изменение материалов только при смене подсвеченного объекта

СОВМЕСТИМОСТЬ:
--------------
Работает со всеми классами, реализующими IRaycastable:
- InteractableObject (базовый класс)
- AIConversant (диалоги)
- Shop (магазины)
- ProcessingStation (станции обработки)
- ChestInventory (сундуки)
- CraftingStation (станции крафта)
- WeaponPickup (подбор оружия)
- HarvestableSource (ресурсы для сбора)
  - TreeSource (деревья)
  - OreSource (руда)
  - HerbSource (травы)
- CombatTarget (цели для атаки)
- ClickablePickup (подбираемые предметы)
