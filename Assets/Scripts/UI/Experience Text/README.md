# Система всплывашек опыта

Эта система отображает всплывашки "Опыт +X" при получении опыта игроком, аналогично системе всплывашек урона.

## Компоненты системы

### 1. ExperienceText.cs
Основной класс для отображения текста опыта. Аналогичен DamageText.

### 2. ExperienceTextSpawner.cs
Спавнер для создания экземпляров ExperienceText. Аналогичен DamageTextSpawner.

### 3. ExperienceTextManager.cs
Менеджер, который автоматически добавляет ExperienceTextSpawner к игроку.

### 4. ExperienceTextTester.cs
Тестовый скрипт для проверки работы системы (нажмите X для тестирования).

## Настройка в Unity

### Шаг 1: Настройка префабов
1. Откройте префаб `Experience Text.prefab`
2. Убедитесь, что компонент `ExperienceText` настроен правильно
3. Проверьте, что цвет текста установлен на медный/темно-золотой (R: 0.8, G: 0.6, B: 0.2)
4. Убедитесь, что анимация `Experience Text Fade.anim` назначена

### Шаг 2: Добавление в сцену
1. Добавьте префаб `Experience Text Manager.prefab` в сцену
2. В компоненте `ExperienceTextManager` назначьте префаб `Experience Text.prefab` в поле `_experienceTextPrefab`

### Шаг 3: Настройка игрока
1. Откройте префаб игрока
2. В компоненте `Experience` добавьте событие `_gainExperience`
3. Назначьте метод `Spawn` из `ExperienceTextSpawner` в это событие

### Шаг 4: Тестирование
1. Добавьте `ExperienceTextTester` к любому объекту в сцене
2. Запустите игру
3. Нажмите клавишу X для тестирования всплывашки

## Автоматическая настройка

Если вы не хотите настраивать префаб игрока вручную, система `ExperienceTextManager` автоматически:
1. Найдет игрока по тегу "Player"
2. Добавит `ExperienceTextSpawner` как дочерний объект
3. Настроит связь с событием `_gainExperience`

## Цвета и стили

- **Цвет текста**: Медный/темно-золотой (R: 0.8, G: 0.6, B: 0.2)
- **Формат текста**: "Опыт +X"
- **Анимация**: Появление, подъем вверх и исчезновение

## Интеграция с другими системами

Система автоматически работает со всеми источниками опыта:
- Добыча ресурсов (HarvestingManager)
- Убийство врагов (Health.AwardExperience)
- Любые другие вызовы `Experience.GainExperience()`

## Устранение неполадок

1. **Всплывашки не появляются**: Проверьте, что `ExperienceTextManager` добавлен в сцену и префаб назначен
2. **Неправильный цвет**: Проверьте настройки цвета в префабе `Experience Text.prefab`
3. **Нет анимации**: Убедитесь, что анимация `Experience Text Fade.anim` назначена в Animator
