СЛЕДУЮЩИЕ ШАГИ:
---------------

1. ОТКРОЙТЕ UNITY EDITOR
   └─> Дождитесь компиляции скриптов

2. ДОБАВЬТЕ ПОДСВЕТКУ КО ВСЕМ ОБЪЕКТАМ
   └─> Меню: Tools > Setup > Add Highlight to All Interactables

3. ПРИМЕНИТЕ ЦВЕТОВЫЕ ПРЕСЕТЫ (опционально)
   └─> Меню: Tools > Highlight Colors > Apply All Presets

4. ПРОВЕРЬТЕ СИСТЕМУ
   └─> Меню: Tools > Validate > Check Highlight System

5. ЗАПУСТИТЕ ИГРУ
   └─> Наведите курсор на интерактивные объекты
   └─> Они должны подсвечиваться!

ЦВЕТОВЫЕ СХЕМЫ:

-----------------

• Оригинальные значения Emission сохраняются и восстанавливаются

ТЕХНИЧЕСКАЯ ПОДДЕРЖКА:
----------------------

Проблемы с компиляцией:
  → Проверьте Console в Unity на ошибки
  → Убедитесь, что все файлы на месте
  → Перезапустите Unity Editor

Подсветка не работает:
  → Tools > Validate > Check Highlight System
  → Проверьте материалы (должны поддерживать Emission)
  → Проверьте наличие Renderer на объектах

Производительность:
  → Система оптимизирована и не должна влиять на FPS
  → При проблемах отключите Include Children для сложных объектов
